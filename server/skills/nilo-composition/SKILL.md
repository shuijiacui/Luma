# Composing a shared drawing

Keep the child's current subject visually dominant. For an open invitation, select one small development of that subject; leave room for the child's next decision. More elements are appropriate only when the child explicitly requests a scene or several parts. Empty canvas is useful space, not a request for scenery.

Read the whole target around the latest child marks. Judge a new detail relative to that individual subject, not the combined bounds of every object. An existing heart elsewhere must not pull attention away from a newly drawn fruit.

Balance the detail's size with the target and brush thickness. Preserve the recognizable outer silhouette. Pick a growth direction with room for the actual strokes; if space is tight, simplify or shorten the same meaningful detail without detaching it. Preserve deliberate asymmetry and the child's palette. Typography, backgrounds and poster decoration are outside a small co-creation turn.

In review, imagine the candidate together with the existing drawing: does the original shape still do useful visual work, and does the new part belong at its actual location? The completed interpretation need not already exist in the input. A circle can become a balloon through a connected string. This is a possibility, never an automatic mapping. Do not reject a useful simple contribution for lacking adult polish, symmetry or extra detail.
