# 周期报告与数据管理

> 2026-09-06 新增功能说明。接口见 [API 契约](API契约.md)，运维见 [部署](部署.md)。

## 周报/月报规则

- 时区固定 Asia/Shanghai，不随服务器系统时区变化。
- 周从周一 00:00 到下周一 00:00；月从当月 1 日到下月 1 日。数据库保存 UTC ISO 时间，左闭右开。
- 只为已经结束且有作品的周期生成。无作品周期不补空报告，进行中周期暂不生成。
- 即使没有单幅解读，也会汇总已有作品；建议只选已有 parentAdvice，不新增模型调用。
- 同一作品内重复元素只计一次；元素展示上限 12 种，建议去重后最多 6 条。activeDays 按本地日期去重。
- 比较的是相邻自然周期作品数，前周期没有保存记录时按 0 处理。数量差值不解释为心理变化。

## 生成与更新

默认创建服务时补齐，之后每小时检查。定时器不会阻止进程退出；嵌入式使用可调用 `app.locals.closeBackgroundJobs()` 停止周期任务。测试默认关闭后台任务。

`PERIOD_REPORTS_ENABLED=0` 关闭后台检查，`npm --prefix server run reports` 和家长 GET digests 仍可补齐。服务停机后的已结束周期会在下次启动或访问时恢复，不依赖单个整点任务是否恰好运行。

唯一键是 child_id + kind + period_start。相同来源不重复生成，报告内容变化会更新来源哈希与生成时间。删除作品或重写单幅报告后清除该孩子旧摘要，再按剩余源记录重建。清除后再生成的摘要 ID 可以变化；集成方以孩子与周期边界识别一个逻辑周期。

当前任务同步读取每个孩子的全部历史并汇总，没有增量队列或分布式调度。大量历史/多实例部署前应评估阻塞时长与任务协调。

## 前端操作与产物

家长导航“周报与月报”支持周/月切换、刷新、分页和单份 JSON 下载。下载含孩子名称、时区、边界、摘要和来源作品编号，不包含认证令牌。

完整成长档案另提供独立 HTML，内嵌原图和已有解读，可离线查看、浏览器打印 PDF。JSON 是可再处理的数据，HTML 是可阅读档案；当前没有服务端直接生成 PDF，也不发邮件或推送。

## 单幅删除

同家庭家长在完整解读选择作品并确认。服务端验证媒体位于受控目录，先暂存图片，再事务删除分析和该孩子的摘要缓存；失败恢复原图。成功后删除暂存文件，异常残留由媒体审计检查。其他家庭、儿童或游客不能执行。

## 注销整个家庭

设置页提供注销，即使尚无孩子也可访问。提交家长密码与“删除整个家庭”后，后端复核身份和密码，事务删除：

1. 家庭内孩子的周期摘要及所有分析/解读。
2. 家庭内全部账号的 access 与 refresh 会话。
3. 全部家庭账号与家庭邀请码记录。

图片先暂存，数据库删除失败则回滚并恢复。提交成功后清理暂存文件；若失败，API 返回 pendingMedia 数量并记录日志。正在等待模型的分析在落库前检查儿童账号仍存在，不会在注销后重建作品。

权限针对整个家庭而非单个儿童；当前没有单独删除儿童账号、第二位监护人迁移或解绑重组家庭的流程。

## 留存与恢复边界

| 数据位置 | 删除/注销后的处理 |
| --- | --- |
| 在线 SQLite 逻辑记录 | 本次删除清除；没有承诺对底层磁盘做取证级擦除 |
| 在线受控媒体 | 提交后删除；失败暂存由运维审计清理 |
| 周期缓存 | 删除作品时失效，注销时清除 |
| 日志与诊断记录 | 由部署方按日志轮换和保留策略处理；注销 API 不清空全站日志 |
| 既有备份 | 默认后续备份任务按 14 天滚动清理；备份任务不运行则不会自行过期删除 |
| 用户导出文件/本机偏好 | 用户自行保管或清除，服务端不能远程撤回 |
| 外部模型/搜索/embedding 服务 | 按服务商设置和协议处理；本项目不承诺跨服务即时删除 |

备份是包含数据库和原图的敏感数据包。恢复会恢复备份时间点的数据，也可能重新带回后来已注销的家庭；正式恢复前应核对备份后的删除事项，必要时先在隔离环境重新执行清理，再开放服务。当前没有独立于备份的永久删除墓碑系统。

`media-audit.mjs` 默认只读，列出缺图与超过一天的无引用受控文件。核实后可显式加 `--remove-orphans`，只处理普通文件，不跟随符号链接。
