# 中文与英文界面

顶部的 `中文 / English` 按钮可在任何页面切换语言。首次访问默认中文，选择保存在浏览器的 `luma_locale` 中；刷新、路由跳转和同源标签页会同步该偏好。浏览器禁用本地存储时，当前页面仍可切换。

## 覆盖范围

- 首页、体验与计划弹窗、登录注册和新手引导。
- 儿童小屋、Nilo 热区提示、欢迎对话、画板工具和保存反馈。
- 家长概览、作品、主题、时间线、沟通建议、周期报告、家庭设置和成长册导出。
- 按钮的无障碍名称、页面标题、文档语言和展示日期。

切换通过 React 外部状态订阅触发更新，不刷新页面、不按语言重新挂载路由。表单输入、画布笔迹、撤销历史及登录状态保持不变。

## 内容与接口

界面标签和已知规则文案按语言展示，用户姓名、作品原文和历史生成的自由文本保留原始内容。首页已有的英文艺术标语作为品牌设计保留。

`POST /api/report` 支持可选的 `locale: "zh" | "en"`，省略或无效值按中文处理。英文请求会本地化基础报告，并要求可选的模型增强输出英文。分类枚举、评分、知识库编号、来源文件名及家庭权限逻辑不随语言变化。新报告记录其生成语言；旧报告默认视为中文。

`POST /api/analyze` 保留原有中文反馈字段，增加 `feedbackTextEn` 和 `followUpEn`，供 Nilo 即时切换。英文反馈根据相同客观特征拼接，不额外调用模型。数字画布反馈继续忽略笔压。

成长册 HTML 按导出开始时的语言生成标签和日期，保留原文、HTML 转义、原图内嵌和令牌排除机制。周期摘要 JSON 仍是原始数据导出，不改写数据字段。

## 维护入口

| 文件 | 用途 |
| --- | --- |
| `shared/locales/en.json` | 前后端共享的中文原文 → 英文词典 |
| `frontend/src/i18n/store.ts` | 语言状态、持久化和标签页同步 |
| `frontend/src/i18n/index.ts` | `t`、`lt` 和 `useLocale` |
| `frontend/src/i18n/LanguageSwitcher.tsx` | 顶部切换入口及文档属性 |
| `frontend/src/i18n/language.css` | 切换栏和英文布局适配 |
| `server/src/services/localization.js` | 报告本地化、英文反馈及输出约束 |

新增界面文案时，在词典中补充英文，在组件内订阅 `useLocale()`，使用 `t('中文原文')` 展示。动态完整句可使用词典中的 `{0}`、`{1}` 模板，避免将多个短语拼成英文句子。不要把翻译后的文字用作数据库值、权限判断、路由或稳定标识；用户原文直接展示。

## 验证

合并远端修复后，前端 25 项测试、后端 86 项测试及前端生产构建全部通过。ESLint 无错误，保留已有引导模块的 8 条警告；构建仍有主包体积提示。

新增测试覆盖语言持久化与跨标签页同步、表单状态保留、用户名保留、英文删除确认映射、双语导出、报告评分不变、数字画布反馈和英文增强输出校验。独立无头浏览器检查了主要页面、桌面与横屏布局，并用实际绘制后的像素快照确认语言切换不清空画布。

测试未调用付费模型服务；真实模型的英文表达质量仍取决于部署时配置的模型。历史自由文本不会在切换时自动调用翻译服务。
