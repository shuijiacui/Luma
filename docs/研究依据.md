# 研究依据与使用边界

> 整理日期：2026-09-18。本文合并仓库已有研究摘录、早期公式讨论及陪伴设计中的来源线索；未重新联网核验文献、复现论文实验或开展儿童研究。保留出处不表示该研究结论已适用于 Luma。

当前功能见[功能与使用流程](功能与使用流程.md)，运行规则见[AI 解读与知识库](AI解读与知识库.md)。本文用于查找原资料、识别证据边界和安排后续核验，不作为产品准确率或临床有效性证明。

## 1. 研究资料怎样进入项目

| 资料 | 在当前项目中的作用 | 不能据此声称 |
| --- | --- | --- |
| [知识条目](../knowledge/entries.jsonl)的 `source`、`note` | 保存特征规则的来源线索与策展备注；条目 ID 用于追溯报告 | 每个特征都已在目标儿童人群中验证，或条目权重就是论文效应量 |
| [约束配置](../knowledge/constraints.json) | 保存年龄影响、冲突登记和参考分值等配置 | 参数已由本产品真实样本校准 |
| `references/` 本地 PDF | 可选文献检索的输入，用于提供研究背景和局限 | PDF 存在即代表其结论支持产品，或检索相似度代表证据强度 |
| 早期陪伴设计所引文献 | 提供儿童自主、可选表达、少预设提问等设计线索 | Nilo 已改善心理健康、表达能力或亲子关系 |

两条文献使用路径需要分开：基础解读使用结构化知识条目及代码规则；可选 PDF 检索为说明补充背景，不改变基础评分，也不自动把新文献写回知识库。[索引脚本](../rag/index_pdfs.py)直接读取 `docs/references/*.pdf`，并保存来源文件名和 SHA-256；因此整理 Markdown 时保留这些 PDF 的原路径。

### 必须保留的冲突与限制

- **天气意象、擦改和重笔触存在解释方向冲突。** 不能选择一个方向后把冲突隐藏；当前冲突登记及处理见配置与技术文档。
- **研究对象与产品任务不等价。** 成人、青少年、指定房树人任务、自由绘画、临床样本与普通家庭样本应分别核对；年龄门控并不能消除全部外推问题。
- **可见笔迹不等于过程测量。** 本画布没有可靠的真实笔压等测量时，不从图片粗细反推笔压；不把静态痕迹解释成真实擦改次数或动机。
- **系统创作不能算作儿童独立证据。** Nilo、模板和儿童笔迹需要保留来源；成长分析与共创规划使用不同图层。接受过共创后，即使撤销 AI 笔迹，仍不能把互动影响假定为不存在。
- **工程参数不是临床测量。** `strength`、`reliability`、`prior`、`fpr`、分值上限和阈值属于策展与配置；不能由他人分类器的误报率直接得出本项目 `fpr`，也不能由负面研究推出“0.85 效度天花板”。
- **验证代码不等于验证人群效果。** 模型交叉审查、公式可达性检查、回归测试、来源 ID 可追溯，都不能代替概率校准、真实样本验证或专业审阅。

早期公式讨论所引 Shafer、Buchanan & Shortliffe、Heckerman、Sentz & Ferson 等，只保留为来源折扣、证据依赖与冲突处理的概念线索。当前实现并非由这些引用验证过的完整统计模型；公式和实际决策顺序统一在技术文档维护。

### 尚未完成的研究维护

`entries.jsonl` 的旧备注、`constraints.json` 的说明文字以及 `dispatch.config.json` 中仍有早期术语和推断，例如“效度天花板”、外部研究支持 `fpr`、`c` 因子降权或旧零命中叙述。本文归整不修改运行数据，也不表示这些元数据已经完成学术核验。实际运行行为以调度/评分代码为准；后续应单独审阅来源和参数，再按知识库变更流程修订，不能只靠改文档宣布已解决。

## 4. 儿童陪伴设计：保留哪些研究方向

早期 5–12 岁方案中，主动邀请共创、先预览再确认、语音可选、保存与识别分离及贡献来源标记已有对应实现。下列更广的设计仍是研究方向，不是已交付功能或已证实效果。

| 原方案留下的来源入口 | 可保留的研究问题与边界 |
| --- | --- |
| [Pons 等 2003](https://onlinelibrary.wiley.com/doi/10.1111/1467-9450.00354) | 年龄、语言理解与个体差异如何影响说明方式；不能把年龄分组直接做成能力诊断。 |
| [Woolford 等 2015](https://researchportalplus.anu.edu.au/en/publications/drawing-helps-children-to-talk-about-their-presenting-problems-du/)；[Davison 与 Thomas 2001](https://www.sciencedirect.com/science/article/pii/S0022096500925670) | 绘画和讲述的配合如何受任务影响；允许只画、不边画边回答，不能假设“说得更多”就是更好的表达。 |
| [Sternberg 等 2001](https://pubmed.ncbi.nlm.nih.gov/11596815/) | 借鉴少预设、承接儿童已经表达内容的提问原则；不移植司法访谈目标与追问流程。 |
| [ASHA AAC 指南](https://www.asha.org/practice-portal/professional-issues/augmentative-and-alternative-communication/)；[NJC 多模态沟通](https://www.asha.org/NJC/AAC/) | 研究素材摆放、指点、图形符号与语音等可选通道；普通素材板不能自称临床 AAC 系统。 |
| [Skene 等 2022](https://srcd.onlinelibrary.wiley.com/doi/full/10.1111/cdev.13730) | 儿童自主与适度帮助的设计线索；原方案已指出成人引导、年龄范围和任务限制，不能外推为 AI 陪伴有效性。 |
| [UNICEF 2026 儿童 AI 陪伴企业建议](https://www.unicef.org/media/181136/file/UNICEF-When-AI-becomes-friend-Business-recommendations-2026.pdf) | 角色透明、退出选择、避免情感挽留及敏感分享边界的规范线索；属于指导资料，不是产品试验。 |

以上外部链接从原方案保留，本次未访问验证可用性或复核全文。

优先待研究的方向：

1. **不依赖语言的完整表达。** 素材摆放、点选作品区域、功能性符号及可访问性设置；目前不能把这些写成已有入口。
2. **可纠正、可删除的记忆。** 区分儿童原话、角色故事、家长输入与模型观察；记录来源、指代、时效和分享范围。当前本地故事摘要不等于这套完整记忆服务。
3. **年龄与支持需要的适配。** 5–7、8–9、10–12 岁只是原稿提出的待验证起点，儿童当下选择和支持需要应优先；沉默、停顿或识别失败不能变成能力标签。
4. **体验与效果分别验证。** 先检查能否自主邀请、拒绝、撤销、保存与退出，再研究长期影响。涉及儿童研究需事先形成合适的知情同意、儿童自愿参与、退出和专业/伦理审阅方案；聊天次数、披露量和使用时长不能代替效果指标。

## 5. 后续资料更新方式

补充一条研究时，先记录准确书目、可访问来源、研究对象、任务、测量与局限，再说明它与哪条规则或设计有关。直接引文、作者解释和项目策展判断应分开；找不到全文或页码的结论标为待核验，不补造数值。

调整运行知识或权重属于独立变更，应同时检查条目、约束、代码、验证与文档；仅添加 PDF 不会使基础规则自动更新。若确需更换或移除 PDF，应检查引用并重建可选文献索引；构建命令见 [rag/README](../rag/README.md)。
