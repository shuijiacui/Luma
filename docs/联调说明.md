# 联调与验收说明

> 更新于 2026-09-08。使用临时测试账号和测试画作，不直接修改已有家庭数据。完整字段见 [API 契约](API契约.md)。

## 启动

使用 Node.js 24，在根目录安装 `npm --prefix server ci` 和 `npm --prefix frontend ci`。将 `server/.env.example` 复制为 `server/.env`，填写实际可用的视觉服务配置。分别启动：

```bash
npm --prefix server start
npm --prefix frontend run dev
```

Vite 已有 `/api` → localhost:3001 代理，无需另写前端地址。若改为跨域 API，可设置 `frontend/.env.local` 的 `VITE_API_BASE_URL`，同时将前端来源加入服务端 `CORS_ORIGINS`。当前是白名单 CORS，有正式账号系统。

`GET http://localhost:3001/api/health` 返回 `{ok:true}` 仅验证 API 进程。实际模型可用性需完成真实画作分析后确认。

## 真实家庭验收

1. 家长在 `/auth?role=parent&mode=register` 注册测试家庭，保存邀请码。
2. 在另一浏览器或独立配置文件，用儿童身份凭邀请码加入。儿童进入 `/child/demo`，打开 `/child/create` 完成画作。
3. 确认分析成功响应含 analysisId，家长在 `/parent/demo` 能看到同一作品原图；不应要求复制儿童浏览器缓存。
4. 展开成长概览的完整解读，选择该作品生成报告；刷新、退出再登录后仍可回看。未填生日不推测年龄，填写后新报告采用生日。
5. 在完整成长档案导出 HTML，离线打开检查原图、日期和已有解读；通过浏览器打印另验 PDF 版式。
6. 切换不同孩子，确认作品、主题、时间轴、建议、周报/月报均属于当前孩子。

## 周期报告验收

周报/月报仅针对北京时间已结束且有作品的周期。刚完成的画作不会立即生成当周/月摘要；当前周期通过创作记录查看。

```bash
npm --prefix server run reports
```

该命令为实际数据库补齐摘要。需要测试边界时优先运行隔离的 `server/tests/period-data.test.js`，其中覆盖周一零点、闰月、跨年、上一周期计数、幂等和源数据删除；不要为了演示修改真实创作时间。

## 权限与失败路径

| 操作 | 预期 |
| --- | --- |
| 儿童 token 调 report、trend、digests | 403；自己的历史 report 为 null |
| 其他家庭家长读作品/报告/摘要 | 403，不生成对方摘要 |
| 过期 access token 提交 | 401，经 refresh 轮换后重试保存；不会变游客 |
| 同键同图像重试 | 返回同一 analysisId；同键换图像 409 |
| 无作品、无孩子 | 清楚的空状态；无孩子仍能进入家庭设置 |
| 特征格式错误 | 400 或提取阶段 502；进程仍健康 |
| 报告增强超时 | 预算内结束等待并保留基础报告 |
| 获取历史失败 | 错误和重试；不显示游客示例 |
| 注销密码错误/确认文案缺失 | 不删除，不退出当前会话 |
| 注销成功 | 所有家庭账号会话失效，在线作品和摘要清除 |

注销及删除验收请使用独立测试家庭。备份与恢复用 [部署指南](部署.md) 的新目录流程。

## 自动化检查

```bash
npm --prefix server test
npm --prefix frontend test
npm --prefix frontend run build
npm --prefix frontend run lint
node knowledge/scripts/validate.mjs
```

本轮受限 Windows 环境不能写已有 `.vite-temp` / `dist` 时，使用以下方式验证同一套配置和源码，产物放工作区临时目录；正常开发环境无需改默认命令：

```bash
npm --prefix frontend test -- --configLoader runner
npm --prefix frontend run build -- --configLoader runner --outDir ../.tmp/frontend-build-period
```

测试替身覆盖工程逻辑，不验证真实视觉/文本模型、搜索、embedding 质量。真实触控、旋转、浏览器打印及生产域名仍需设备和运行环境验收。当前验证结果见 [功能完成度](功能完成度.md)。
