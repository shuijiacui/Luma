# 联调与验收

> 更新于 2026-09-18。本文提供可执行检查步骤，不沿用旧阶段报告的测试数字或通过结论。自动化替身、浏览器检查、真实设备和真实供应商验收分别记录。

## 1. 启动与配置检查

在仓库根目录使用 Node.js 24：

```bash
npm --prefix server ci
npm --prefix frontend ci
```

复制 `server/.env.example` 为 `server/.env`，使用目标服务实际支持的视觉模型；语音与文献 embedding 分别配置，不复用绘画密钥。具体变量见[部署](部署.md)和 [Nilo API](../server/NILO_API.md)。

两个终端分别启动：

```bash
npm --prefix server run dev
```

```bash
npm --prefix frontend run dev
```

官网为 `5173`、家长端 `5174`、儿童端 `5175`，三者代理 `/api` 到 `3001`。前端命令不启动后端。开发后端应自动重载，避免前端更新后仍访问旧接口。

- `/api/health` 返回 `{ok:true}` 只说明进程响应，不能证明模型可用。
- `node server/scripts/diagnose-nilo.mjs` 默认只检查配置就绪情况；`--live` 才会用合成图发起一次真实模型请求并产生用量，不应混入普通自动化检查。
- 手机联调将三端地址设为设备可访问的地址，不能让手机跳转到自己的 localhost；跨域 API 需配 CORS。生产麦克风要在 HTTPS 与真实授权下验收。

## 2. 自动化检查

```bash
npm --prefix server test
npm --prefix frontend test
npm --prefix frontend run build
npm --prefix frontend run lint
node knowledge/scripts/validate.mjs
```

修改单个模块时先跑相关用例，再按影响范围执行全量检查。独立端发布还需验证对应 `build:parent` / `build:child`；三种构建默认共享 dist，需要分别指定输出目录或及时部署产物。

| 改动范围 | 重点测试位置 |
| --- | --- |
| 比例、碰撞、整组提案 | `frontend/tests/companion-proposals.test.ts`、`companion-controller.test.tsx` |
| 笔迹、来源、保存与撤销 | `drawing-canvas.test.tsx`、`companion-scene.test.ts`、`nilo-drawing-integration.test.tsx` |
| 尺寸与工具栏 | `drawing-surface.test.ts`、`drawing-surface-resize.test.tsx`、`drawing-tools.test.tsx` |
| 语音与音乐 | `companion-voice.test.tsx`、`drawing-music.test.tsx` |

测试结果应记录提交号、命令、环境、通过/失败项和未覆盖部分。旧记录中的测试数量不是当前门槛，构建通过也不代表语音服务或真实设备已验收。

## 3. 真实家庭主流程

使用新建测试家庭及测试画作，不为演示修改已有家庭或真实创作时间。

1. 从官网分别点击双端入口，确认直接打开对应登录页，并可返回官网。
2. 注册家长账号，复制邀请码；另一浏览器或独立配置文件注册儿童账号并加入。无孩子、无作品和网络失败应分别显示，不能用游客数据填充正式家庭。
3. 家长填写孩子生日；未填生日时不猜测年龄。创建第二个测试孩子，切换时确认作品与异步结果不串号。
4. 孩子从大门新建，画几笔后点“保存”。儿童历史能续画，家长分析历史此时不应新增记录。
5. 点“完成”，确认先保存再分析。成功响应含 `analysisId`，画布留在原页显示反馈；分析失败时已保存作品仍可打开。
6. 家长电脑端点击最近作品右上日期/箭头展开完整解读，选择对应记录，生成并回看报告。“本周成长摘要”的查看详情只是进入创作记录。
7. 在另一设备或重新登录后确认历史原图与报告可读，不依赖儿童浏览器缓存。生成/删除解读后相关概览及时更新。
8. 直接访问家长端 `/parent/archive`，导出 HTML，离线检查图片、日期和已有解读；另用浏览器打印检查 PDF。当前主界面尚缺档案跳转按钮。

## 4. 共创、语音与画布

| 检查 | 预期结果 |
| --- | --- |
| 首次进入空白画布 | 选择自己画/一起画；历史作品直接续画，不强制半圆热身或自动多步工具引导 |
| 画船并说“这是飞船” | 以孩子明确叙事为优先，建议与当前作品相关；语义质量需真实模型单独评测 |
| 点击 Nilo 交接回合 | 不申请麦克风、不播放 TTS；规划完成先显示投影，未确认不写入作品 |
| 1–4 元素组合 | 物理比例合理，附近避让；移动、缩放、换色作用于整组，确认一次提交，Nilo 撤销一次恢复 |
| 模板外的自定义物体 | 请求机器人、恐龙等物体，检查自定义轮廓是否可辨、关键细节是否清楚，与儿童笔刷一致；手机与桌面保持物体比例 |
| 自定义协议与预算 | 无效路径、越界坐标、超出 24 路径/物体或 64 笔迹/组时整组拒绝；拒绝一个物体后可继续请求其他自定义物体 |
| 笔刷风格与高分屏 | 沿用孩子笔刷、颜色和粗细；不同 DPR 下预览与确认后的路径和纹理一致 |
| 投影期间保存/下载 | 投影与引导轮廓不进入导出；继续画、切作品、取消或改尺寸使旧结果失效 |
| 保存、重开共创作品 | 保留笔迹文档和分组撤销；家长展示合成图，成长分析只使用孩子层，并标记共创影响 |
| 旧 PNG 缺来源 | 可续画、保存；不伪造作者归属，不直接生成新的儿童特征分析 |
| 麦克风与播报 | 主动开始；显示识别结果，可结束本段、打断播报、停止；关闭播报不禁用收音能力 |
| 确认短语 | “留下来”才提交；“好看”“我喜欢”“不要留下来”“好看吗”不误提交 |
| 本地调整 | “小一点”“往左”“换成蓝色”等不请求绘画模型；换想法可能产生新请求 |
| 连续交流与离页 | 主动开启，达到轮数/时长上限或停止、切后台后释放录音与播放，不自行恢复 |
| 识别失败或权限拒绝 | 提示真实原因，可以重试或使用按钮；不会把无识别结果当作确认 |
| 音乐 | 顶部独立控制，语音期间降低音量，结束后恢复用户设置 |

真机语音验收分别测试中文/英文、儿童发音、噪声、权限、设备麦克风及供应商网络。浏览器有识别 API 或 `/voice/config` 返回 true，不等于实际识别可用；云端与浏览器降级分别验收。

## 5. 设备、语言与无障碍

- 在桌面、横竖平板、小手机上检查画布、底部按钮、调色盘和英文长文案。展开/收起工具时记录画布坐标与尺寸，二者应一致；真实窗口变化时保持原画比例。
- 手机儿童端尝试横屏但不阻断；不支持方向锁定时页面仍可用。实测 Safari、目标安卓浏览器及安装模式，不将模拟视口当作系统转屏验收。
- 家长桌面保留侧边布局，手机保留独立顶部/底部导航。检查内部滚动和安全区，不能强行把长报告压进一屏。
- 现有手机家长端完整解读入口缺失、概览月报卡的状态含义和静态通知等限制以[功能与使用流程](功能与使用流程.md)为准，不在演示中掩盖。
- 中英切换不清空表单、笔迹或撤销历史；用户昵称和历史自由文本不自动改写。新报告按请求语言生成，存量报告保留原文。
- 新手引导检查可见目标、异步准备、目标消失、实际笔画完成、Escape/Tab/焦点恢复、账号隔离和跳过记录。角色热点检查连续点击取消、键盘操作及减少动态效果。

## 6. 权限、故障和数据生命周期

| 场景 | 预期结果 |
| --- | --- |
| 儿童调用报告、趋势、周期摘要 | 403；自己的分析历史不返回家长报告 |
| 跨家庭读取或删除 | 拒绝访问，不为对方生成报告/摘要 |
| 过期 access 或退出时迟到响应 | 刷新轮换或提示重新登录，不降为游客；旧响应不能恢复会话或写入新账号 |
| 同提交键重试、同键换图、画册版本变化 | 相同内容复用记录；冲突返回错误，不重复记录或覆盖新版本 |
| 特征格式错误、模型断开、增强超时 | 错误可恢复，API 仍健康；报告增强失败保留基础报告，共创不自动付费重试 |
| 共创取消和绘画/语音限流 | 迟到内容不落笔；语音使用独立额度，仍受全局限制 |
| 家长删除分析 | 删除分析副本并使周期摘要失效，儿童可编辑原稿仍在 |
| 家庭注销失败/成功 | 错密码不删、不退出；成功清除家庭的画册、分析、摘要和会话；媒体残留有运维提示 |

周期使用北京时间已结束自然周/月。测试周一边界、闰月、跨年、无数据、来源改变与重复补齐；优先运行隔离的 `period-data.test.js`。`npm --prefix server run reports` 会对实际数据库补齐摘要，不应为验收篡改真实记录日期。

删除与注销使用独立测试家庭；备份恢复使用[部署指南](部署.md)中的新目录，核验原图哈希与删除后恢复风险。语音原文/录音不应写入项目持久日志，导出文件不得包含令牌。

## 7. 记录验收结论

每次发布记录“在哪个提交、哪种设备/浏览器、哪种配置下，通过了哪些场景”。没有实际执行的供应商调用、儿童语义质量、弱网触控、打印和生产恢复应标为未验收；不要将工程测试数量换算为模型准确率或产品效果。
