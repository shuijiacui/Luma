# 首页湖畔设计

首页采用简洁湖畔插画，底部仅保留“儿童端 → / 家长端 →”一行入口。订阅计划按钮及原有三个方案保留。未登录时进入对应角色登录页；同角色已登录时直接进入对应空间；打开另一角色登录页不会提前退出当前会话。

沿用项目现有非儿童页面的横屏提示。已检查 1672×941、1024×768、844×390 布局及订阅弹窗开关、Escape、角色导航与键盘入口。手机竖屏仍显示项目原有的旋转屏幕提示。
