## 维护约定

1. 功能状态与用户入口只在《功能与使用流程》中维护；修改功能时同步其限制和步骤。
2. 字段与权限更新《API 契约》，模块关系更新《架构与数据流》，现行观察与文献使用范围更新《心理知识资产》。具体 Nilo 协议保留在服务模块文档，通过链接引用。
3. 验收步骤集中在《联调与验收》。测试数量和服务是否通过以实际执行结果为准，不沿用旧阶段报告。
4. 研究假设、商业计划与当前功能分开；文献结果不能直接当作本项目的准确率或临床有效性。
5. 不为同一功能重复建立“方案、完成度、改进总结、修复说明”。过程记录使用提交或 PR，持续说明更新对应主文档。
