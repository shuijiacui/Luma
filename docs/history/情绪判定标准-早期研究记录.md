# 情绪判定标准

> 特征 → 情绪的映射规则总表。每条规则对应知识库条目，必须附文献出处。
> **不允许主观臆断**——查不到文献的特征不入库，或标 TBD + 低权重。

## 情绪输出枚举（红线：只允许这 6 个词）

| 输出 | 含义 | 产生方式 |
|------|------|----------|
| 乐观平稳 | 有**积极证据**（乐观组条目命中且分值过阈） | 知识库条目命中 |
| 未见明显风险信号 | 知识库零命中——missing evidence，**不是**积极证据 | 评分逻辑（零命中分支） |
| 焦虑倾向 | 存在焦虑相关特征组合（≥2 独立簇） | 知识库条目命中 |
| 低落倾向 | 存在低落相关特征组合（≥2 独立簇） | 知识库条目命中 |
| 需要关注 | 信号冲突、弱预警带、多方向信号或单簇强信号 | 评分逻辑产生（非条目） |
| 信息不足 | 置信度不足、提取失败或参数/引用校验失败 | 评分逻辑产生（非条目） |

⚠️ "未见明显风险信号"与"乐观平稳"必须严格区分（v2.3 交叉验证修正）：前者是"知识库没覆盖到"，后者是"发现了积极特征"。家长端文案不得混用。

## ⚠️ 效度免责声明（路演答辩必读）

**HTP 类投射测验的效度在学术界存在严肃争议：**

- Lin et al. (2022, *Acta Psychologica*, 230:103734, n=4196)：DNN 实证发现**现有 HTP 指标与心理健康问题无可靠关联**
- Lilienfeld, Wood & Garb (2000, *PSPI* 1(2):27-66)：投射技术缺乏已确立的效度、信度和已知误差率

**本产品的应对（也是设计红线）：**

1. 定位是**情绪预警筛查**而非诊断——效度争议最强的恰恰是诊断用途
2. 置信度**硬天花板 0.85**（score.js Step 5），任何输出不得突破
3. 采用**结构化特征评分**而非整体印象式解读——正面证据支持结构化路线：Guo et al. (2023, Frontiers in Psychiatry, 13:1041770) meta 分析显示 HTP 结构化评分有筛查价值；TDT-SIAS (2025) 结构化树木评分量表达 sens 0.935 / spec 0.966
4. 每条判定必须引用可溯源文献条目，无出处 → reliability 0.1 折扣

## 判定原则（讨论共识）

1. **宁可信其有，但只输出高置信度**——阈值 0.7，达不到就诚实说"信息不足"
2. **单一特征不定论**——"太阳涂黑"这类单一弱信号 weight 必须低到无法单独越阈，需与其他特征共现
3. **结果只给家长**——孩子视角不展示任何判定
4. **只给倾向和沟通建议**——不给诊断、不给干预方案
5. **每条判定可溯源**——必须引用知识库条目 ID

## 经典特征方向（种子数据覆盖范围，具体权重以文献为准）

> ⚠️ 以下是入库的**特征方向清单**，不是判定规则本身。每条入库时必须找到文献出处定 weight。

### 低落倾向相关
- 深色（黑/灰）占比过高
- 画面主体过小、位于角落
- 人物缺失或人物无表情/背面
- 太阳/光源被涂黑或遮蔽（弱信号，需共现）

### 焦虑倾向相关
- 笔触压力过重、反复涂抹
- 大量涂改痕迹
- 元素扭曲变形（树干弯折等）
- 画面拥挤、元素堆叠

### 乐观平稳相关
- 色彩丰富、暖色主导
- 画面饱满、主体居中
- 人物完整、有互动元素（房屋有人、树有果）

## 文献优先级

1. 房树人（HTP）测验经典文献（Buck, Hammer 等）
2. 儿童绘画心理治疗专著（《儿童绘画与心理治疗》等）
3. 同行评审论文（DOI 可溯源）
4. 无出处 → TBD + weight ≤ 0.1
