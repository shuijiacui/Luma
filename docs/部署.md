# 生产部署指南

> 目标形态：单台 VPS + Caddy 自动 HTTPS + systemd 守护 + cron 每日备份。合规文本（隐私政策等）另行处理，不在本文档范围。

## 架构

```
公网 HTTPS ──▶ Caddy（443，自动证书）──▶ 127.0.0.1:3001（node server）
                                              ├── /api/*        判定 + 账号 API
                                              ├── /*            前端静态产物（FRONTEND_DIST）
                                              ├── data.sqlite   账号/历史
                                              ├── logs/         app.log + audit.log（JSONL）
                                              └── backups/      每日备份（cron，14 天滚动）
```

前后端同域部署，生产环境**不需要 CORS**（白名单仅用于本地开发）。

## 步骤

```bash
# 1. 服务器准备（Ubuntu，Node ≥ 22.5）
sudo useradd -r -m -d /opt/luma luma || true
sudo mkdir -p /opt/luma && sudo chown luma:luma /opt/luma

# 2. 拉代码 & 构建
sudo -u luma git clone https://github.com/shuijiacui/Luma.git /opt/luma
cd /opt/luma/frontend && sudo -u luma npm ci && sudo -u luma npm run build
cd /opt/luma/server && sudo -u luma npm ci --omit=dev

# 3. 配置（server/.env，权限 600）
LLM_BASE_URL=https://api.openai-next.com/v1
LLM_API_KEY=sk-***               # 真实 key，禁止提交
LLM_VISION_MODEL=o3-pro
LLM_TEXT_MODEL=kimi-k2.5
PORT=3001
TRUST_PROXY=1                    # Caddy 反代后取真实 IP 限流
FRONTEND_DIST=/opt/luma/frontend/dist
DB_PATH=/opt/luma/server/data.sqlite
BACKUP_DIR=/opt/luma/server/backups
# CORS_ORIGINS=                  # 生产留空（同域）；本地开发才需要

# 4. systemd 守护
sudo cp /opt/luma/deploy/luma-server.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now luma-server

# 5. HTTPS（Caddy）
sudo cp /opt/luma/deploy/Caddyfile /etc/caddy/Caddyfile   # 改域名
sudo systemctl reload caddy

# 6. 每日备份
sudo -u luma crontab /opt/luma/deploy/backup.cron
```

## 验证清单

| 检查 | 命令/方法 | 预期 |
|------|-----------|------|
| 健康 | `curl https://域名/api/health` | `{"ok":true}` |
| SPA | 浏览器开域名 | 前端页面，无 CORS 报错 |
| 限流 | 连续 20+ 次错误登录 | 429 + Retry-After |
| token 轮换 | 前端静置 2h 后操作 | 自动 refresh，不跳登录 |
| 备份 | `ls /opt/luma/server/backups/` | 每日一个 `luma-*.sqlite` |
| 审计 | `tail logs/audit.log` | 每次判定一行 JSONL（命中条目+kbVersion） |

## 故障恢复

```bash
sudo systemctl stop luma-server
cp /opt/luma/server/backups/luma-<最新>.sqlite /opt/luma/server/data.sqlite
sudo systemctl start luma-server
```

## 环境变量全表

| 变量 | 默认 | 说明 |
|------|------|------|
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_VISION_MODEL` / `LLM_TEXT_MODEL` | — | LLM 配置（必填） |
| `PORT` | 3001 | |
| `TRUST_PROXY` | 关 | `1` = 信任反代 X-Forwarded-For（限流按真实 IP） |
| `FRONTEND_DIST` | 关 | 设置后托管前端静态产物（SPA 回退） |
| `CORS_ORIGINS` | `http://localhost:5173` | 逗号分隔白名单；生产同域留用默认即可（浏览器不跨域） |
| `DB_PATH` | `server/data.sqlite` | |
| `BACKUP_DIR` | `server/backups` | |
| `BACKUP_RETENTION_DAYS` | 14 | 备份保留天数 |
| `RATE_LIMIT_GLOBAL` / `RATE_LIMIT_AUTH` / `RATE_LIMIT_ANALYZE` | 600 / 20 / 60 | 15 分钟/15 分钟/1 小时窗口 |
| `ACCESS_TOKEN_TTL_MIN` | 120 | access token 有效期（refresh token 固定 30 天，轮换） |
| `CONFIDENCE_THRESHOLD` / `CONFIDENCE_CEILING` / `PRIOR_DISTRESS` / `PRIOR_POSITIVE` / `FALSE_POSITIVE_RATE` | 0.7 / 0.85 / 0.15 / 0.60 / 0.05 | 评分参数（勿随意改，score.js 有可达性断言） |
