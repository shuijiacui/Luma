# 引导体系设计

> AI 反馈话术规范。核心原则（讨论共识）：**极度克制**——语言和语音都会造成儿童表达失真，引导必须最小化、非诱导。

## 为什么克制

- 文字/语音表达经过人为修饰，低龄儿童难精准匹配词汇与感受
- 引导性提问会让孩子刻意隐瞒或伪装真实情绪（"上课睡觉借口作业多"效应）
- AI 绘画引导主观干扰强，降低判定可信度
- 结论：**AI 只做镜子（描述画面），不做教练（引导情绪）**

## ✅ 允许话术（白名单）

### 描述性反馈（模板拼接，不调 LLM）

```
"我看到你画了{elements}。"
"你又加了{newElements}。"
```

- 只含客观元素名词，不含形容词、不含情绪词

### 开放提问（全程唯一）

```
"想再画点什么吗？"
```

## ❌ 禁止话术（黑名单）

| 类型 | 示例 | 原因 |
|------|------|------|
| 情绪诱导 | "你是不是很难过？" | 暗示答案，造成伪装 |
| 情绪命名 | "你画得很孤独" | 替孩子定义感受 |
| 选择题引导 | "你是在等人，还是喜欢一个人？" | 限定表达范围 |
| 评价性措辞 | "画得真好/真乱" | 影响后续表达 |
| 解读性措辞 | "黑色太阳说明你…" | 诊断越界 |
| 追问 | "为什么画这个？" | 压迫感，引发编造 |

## 实现约束

- `feedbackText` 由 features 模板拼接（server/src/services/report.js），**不调 LLM**
- `followUp` 固定文案，硬编码于代码
- 特征提取 prompt（llmClient → DeepSeek Vision）必须含："你是儿童绘画观察员。只描述画面客观元素，不做任何心理解读"
- 单测断言：feedbackText 不含情绪词/诱导词（正则黑名单）

## 家长侧建议文案（模板，非干预方案）

> 以 `server/src/services/report.js` 的 `PARENT_ADVICE` 表为准（实现回填 2026-07-25）：

| emotion | parentAdvice |
|---------|--------------|
| 乐观平稳 | 画面中出现了积极的信号，继续保持日常的亲子互动与陪伴；鼓励孩子多用绘画表达自己 |
| 未见明显风险信号 | 本次画面未出现知识库收录的风险信号，继续保持日常陪伴与观察；单幅画能反映的信息有限，建议结合日常状态综合了解孩子 |
| 焦虑倾向 | 近期多安排轻松的亲子共处时间，避免直接追问；留意孩子的睡眠与饮食变化，保持规律作息；先倾听、少评价，让孩子自己说 |
| 低落倾向 | 多倾听孩子的想法，不急于评价或纠正；增加户外活动和同伴交往的机会；持续观察，可与学校老师沟通了解在校状态 |
| 需要关注 | 画面中出现了需要留意的信号，建议近期密切观察孩子的状态；保持耐心倾听，避免质问式沟通；如类似信号持续出现，可考虑寻求专业心理咨询资源 |
| 信息不足 | 本次画面信息不足，建议继续观察 |

红线："需要关注"只允许建议"寻求专业心理咨询资源"，产品自身不提供任何咨询内容；所有建议文案过红线正则双保险（命中疾病词 → 降级"信息不足"）。
