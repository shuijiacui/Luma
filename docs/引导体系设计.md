# 引导体系与反馈边界

> 当前实现，2026-09-08。此文描述产品话术约束，不把早期讨论中的心理机制猜测作为研究结论。

儿童侧以描述画面和开放提问陪伴作画。`buildFeedback` 将可见元素、颜色及构图组织成模板，固定 followUp 为“想再画点什么吗？”。不调用文本模型生成儿童心理解读，也不对孩子展示家长报告。

每次识别当前完整快照，不计算“又增加了哪些元素”，也不使用历史并集评价新的画面。数字画板反馈与评分排除未测量的真实笔压和擦除次数证据。

儿童反馈不应暗示情绪答案、替孩子命名感受或把单幅画解释为现实状态。画面内容也可能被模型识别错，不能把模板输出称为不会失真的客观事实。

家长 parentAdvice 由基础模板与命中簇建议组成；另可通过受约束的文本模型生成 narrative、证据通俗化及联网建议。增强有输出校验和整体等待预算，失败保留基础结果。说明与文献背景不改变评分。

家长沟通助手把已有建议呈现为可展开的提示卡，不是自由输入的聊天机器人；长期记忆和多轮对话没有实现。UI 中的 AI 描述必须标明来源，不能标成孩子原话。

具体文案以 `server/src/services/report.js` 为准，接口以 [API 契约](API契约.md) 为准；产品输出语义见 [情绪输出标准](情绪判定标准.md)。
