## 判定链路三段式

1. **特征提取（LLM，只此一处调 LLM）**: `deepseek-v4-flash-vision-exp` 视觉模型，prompt 限定"只描述画面客观元素，不做任何心理解读"，输出固定 schema JSON。LLM 不接触情绪判定。
2. **检索（纯代码）**: 标签匹配器遍历知识库条目，`featureMatch` 条件全满足即命中。
3. **评分（纯代码）**: 按 emotionSignal 分组累乘置信度，阈值 0.7，红线校验后输出。

## 关键设计决策

| 决策 | 理由 |
|------|------|
| LLM 只做特征提取，不做判定 | 判定必须可追溯（引用知识库条目 ID），LLM 直接判定无法溯源 |
| feedbackText / parentAdvice 模板化，不调 LLM | 防诱导措辞、防信息失真（讨论核心结论） |
| 知识库 JSONL + 标签匹配，不用向量库 | MVP 阶段条目量级小（<100），标签匹配可解释、可测试 |
| 置信度公式 v2 | v1 的 `1-Π(1-w)` 是 MYCIN CF 合并，要求证据独立会重复计数。v2：簇内 max 去重 → 簇间 noisy-OR → 贝叶斯后验（引入基率）→ 0.85 效度天花板。数学依据见 RAG设计.md 审查记录 |
| 冲突信号（乐观+低落同时≥0.5）→ "需要关注" | 不做武断取舍，交给家长；不采用 Dempster 规则（Zadeh 反例证明高冲突下反直觉） |
| 信源折扣（Shafer discounting） | 条目 reliability 字段显式表达文献质量：meta 0.9 / 单研究 0.7 / 专著 0.5 / TBD 0.1 |

## 架构界限（防幻觉边界，不可违反）

核心原则：**LLM 只存在于一个受控入口，判定路径全程确定性代码。**

```
                    ┌─── LLM 区（唯一入口，幻觉只能从这里进）───┐
 画作 ──▶ extractFeatures ──▶ FeatureJSON ──▶ retrieve ──▶ score ──▶ report
           (DeepSeek 视觉)    (schema 校验      (纯代码)    (纯代码)  (模板,
            只描述不解读       +置信度过滤)                          不调LLM)
                    └────────────────────────────────────────────────┘
                              ↑ 过了这道门，后面没有任何生成式模型
```

| 层 | 允许什么 | 禁止什么 | 越界后果 |
|----|---------|---------|---------|
| **L1 特征提取**（LLM） | 描述画面客观元素，输出 schema JSON + 每特征 confidence | 出现任何情绪词/解读词；输出 schema 外字段 | schema 校验拒绝，整次分析作废重试 |
| **L1→L2 闸门**（代码） | confidence ≥ 0.5 的特征通过 | 低置信特征进入检索 | 直接丢弃，记日志 |
| **L2 知识库**（JSONL） | 人工策展、真实文献 source、CI 校验通过 | 由 LLM 生成/修改条目；无 source 的高权重条目 | validate.mjs 退出码 1，禁止合入 |
| **L3 检索+评分**（代码） | 标签匹配、权重叠加、阈值判定 | 调用任何 LLM；输出无条目 ID 的判定 | 不存在此代码路径（架构上不可能） |
| **L4 输出**（模板） | 固定模板填空：倾向 + 置信度 + 条目 ID + 文献 note | LLM 润色判定文案；疾病词；引用不存在的 ID | 红线正则 + ID 存在性校验 → 降级"信息不足" |

**为什么是硬界限而不是约定**：L3/L4 的代码里不 import llmClient，依赖注入清单里没有它——越界在编译/评审期就能发现，不靠自觉。

## v2 扩展的界限（预先划定）

| 扩展 | 允许的位置 | 永远不允许 |
|------|-----------|-----------|
| 向量检索 | 只做 L2 的候选召回，命中仍走标签过滤 | 向量相似度直接作为判定依据 |
| 贝叶斯概率 | score.js 内替代/融合权重叠加，概率必须来自文献统计（source 可引） | 凭空调参填概率——无文献的概率字段保持空，走 weight 兜底 |
| 像素/CNN 模型 | 独立第三路信号，低权重，仅边界 case 纠偏 | 出现在给家长的"判定依据"里；单独越阈出结果；用抑郁/健康临床标签 |

依据：FBANet 论文（[文献提取-FBANet.md](文献提取-FBANet.md)）证明可解释特征路线（SVM + 人工特征）达 85–91% 准确率，且像素模型数据集不公开、标签为临床诊断——与产品"情绪预警非诊断"边界冲突。
