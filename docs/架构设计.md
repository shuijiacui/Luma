# 架构设计

> 当前代码结构，2026-09-06。主路径：React 前端 → Express API → SQLite / 受控媒体。可选模型与文献检索位于可降级的外部依赖边界。

## 模块与职责

| 模块 | 职责 | 实现 |
| --- | --- | --- |
| 前端应用 | 双角色路由、会话、画布、家长视图、导出 | `frontend/src/app`、`features`、`hooks`、`lib/api` |
| 请求入口 | JSON、CORS、限流、认证上下文、静态托管、错误处理、周期调度 | `server/src/app.js` |
| 账号与家庭 | scrypt 密码、会话与刷新、邀请码、生日、家庭注销 | `routes/auth.js`、`authService.js`、`familyDeletion.js` |
| 画作与解读 | 提取、保存、图片读取、删除、报告编排 | `routes/analyze.js` |
| 知识库 | 特征验证与门控、分层调度、确定性评分、模板与输出校验 | `extractFeatures.js`、`kbDispatcher.js`、`score.js`、`report.js` |
| 历史与周期 | 历史查询、描述性趋势、周报/月报 | `historyService.js`、`periodReports.js` |
| 可选增强 | 文本模型、Bocha 搜索、Python 文献检索 | `llmClient.js`、`webSearch.js`、`referenceRag.js`、`rag/` |
| 运维 | 内嵌原图备份、校验恢复、缺图/孤儿审计、手动周期补齐 | `server/scripts/` |

## 两条核心数据流

儿童完成画作 → 校验完整 base64 快照 → 视觉模型输出特征 → schema 校验与逐维质量门控 → 模板反馈。正式儿童账号同时保存受控原图及分析记录；游客不落家庭库。同孩子、同提交键、同图像重试返回既有记录，不同图像复用键返回冲突。

家长选择作品 → 权限校验 → 从服务端读取特征及生日 → 分层知识库调度 → 确定性评分与审计 → 基础报告 → 可选说明/证据通俗化/文献背景/联网建议 → 保存并返回。外部增强不能修改评分输入或基础情绪标签，超预算退回基础结果。

这不是“模型只调用一次”的架构：视觉模型负责感知，可选文本模型负责组织说明。可复现的是给定特征、知识库与配置时的评分结果，不能据此声称图像模型输出完全确定。

## 存储模型

| 表 / 文件 | 保存内容 |
| --- | --- |
| `families` | 家庭 ID、邀请码 |
| `accounts` | 角色、家庭、账号标识、密码/创作码哈希、可选生日 |
| `sessions` | access token、账号、过期时间 |
| `refresh_tokens` | refresh token 哈希、账号、过期时间 |
| `analyses` | 孩子/家庭、完整特征、反馈、原图元数据、报告与审计、幂等键 |
| `period_reports` | 孩子、周期类型/边界、摘要 JSON、来源哈希、生成时间 |
| `UPLOAD_DIR` | 受保护图片文件；由有权限的 API 请求读取 |

启动执行增量建表/加列，兼容旧数据，不自动改写历史特征或报告。新增周期表以 `(child_id, kind, period_start)` 唯一约束保持幂等。摘要按源数据重建；删除画作立即清除相关摘要缓存。

## 会话与权限

access token 默认 120 分钟，refresh token 30 天并轮换；退出撤销该账号所有会话。前端并发刷新共享请求，过期响应不能在退出或换账号后恢复旧会话。真实账号历史依服务端家庭关系授权，不以页面隐藏代替权限。

儿童本人可读自己的作品和图片，家长可读同家庭孩子数据。报告、趋势、周期摘要、生日修改和删除仅家长可用。匿名只允许临时图像分析/特征报告演示，不能读取真实作品编号。

## 周期任务与数据生命周期

周期任务在服务启动时和每小时同步运行，按北京时间生成已结束且有作品的自然周/月。页面读取也触发补齐，服务停机不会永久漏报。任务不调用模型，不推送站外通知。`PERIOD_REPORTS_ENABLED=0` 只关闭后台任务，手动命令和页面补齐仍可用。

单幅删除和家庭注销先将受控图片暂存，数据库删除失败时恢复文件；提交后删除暂存文件。文件清理失败会记录日志，家庭注销返回 `pendingMedia`，可通过媒体审计处理残留。注销同时撤销全部家庭账号会话，进行中的分析不能在注销后重新落库。

备份使用 SQLite 快照并内嵌媒体字节/哈希；恢复验证后输出新目录。历史备份、已下载档案和外部模型数据留存独立于在线删除。详见 [周期报告与数据管理](周期报告与数据管理.md)。

## 部署与扩展边界

主服务可同域托管前端，基础评分不依赖 Python。文献 RAG 启用后通过子进程访问本地 Chroma；embedding 与视觉/文本服务独立配置。

当前使用同步 SQLite 和进程内定时器/限流，适合单进程 MVP；没有分布式任务队列、跨实例限流或支付系统。多实例部署前需要重新设计任务协调、存储和限流，不能直接当作已验证的高并发架构。
