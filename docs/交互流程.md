# 交互流程

> 前端开发唯一依据。每页定义：用户动作 / 系统行为 / AI 行为 / 输出数据。
> 红线：孩子视角全程无判定结果展示；判定只给家长。

## P1 欢迎页

- **用户动作**: 打开产品，看到形象 IP
- **系统行为**: 展示 IP 形象 + "开始画画"按钮
- **AI 行为**: 无（纯视觉引导，无文字问卷）
- **输出**: 无

## P2 画板页

- **用户动作**: 自由绘画（无命题），可用画笔/颜色/橡皮/清空，点"完成"
- **系统行为**: 画布记录笔触；完成时导出 PNG → base64
- **AI 行为**: 无（作画过程零打扰）
- **输出**: `imageBase64` → `POST /api/analyze`

## P3 AI 反馈页

- **用户动作**: 观看 AI 反馈
- **系统行为**: 调 `/api/analyze`，展示反馈
- **AI 行为**: **只描述画面客观内容**——"我看到你画了房子、树和一个人"（由 features 模板拼接，不调 LLM 生成，防诱导措辞）
- **输出**: `features`（FeatureJSON）、`feedbackText`

## P4 开放提问

- **用户动作**: 选择"再画一点"或"画完了"
- **系统行为**: 展示唯一开放问题
- **AI 行为**: 仅允许一个开放问题："想再画点什么吗？"
- **禁止**: 任何情绪诱导（"你是不是很难过"）、任何选择题式引导
- **输出**: 用户选择分支

## P5 补充绘画（可选）

- **用户动作**: 孩子可再画
- **系统行为**: 再次 `POST /api/analyze`（带 `priorFeatures`），特征并入判定
- **AI 行为**: 同 P3，只描述新增内容
- **输出**: 合并后的 `features`

## P6 结果页（家长视角，需家长确认进入）

- **用户动作**: 家长点击"家长查看"（简单确认，非登录）
- **系统行为**: `POST /api/report`
- **AI 行为**: 无（报告由模板生成，不调 LLM）
- **输出展示**:
  - 情绪倾向：乐观平稳 / 焦虑倾向 / 低落倾向 / 需要关注 / 信息不足
  - 置信度数值（如 0.82）
  - 知识库依据列表（条目 ID + 摘要）
  - 家长沟通建议（模板化，非干预方案）
- **禁止**: 疾病名、诊断措辞、干预方案

## 页面与 API 对照

| 页面 | API |
|------|-----|
| P2/P5 完成绘画 | `POST /api/analyze` |
| P6 结果页 | `POST /api/report` |
| 全局 | `GET /api/health` |

详见 [API契约.md](API契约.md)
