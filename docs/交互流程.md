# 交互流程

> 当前双端行为，更新于 2026-09-06。权限及数据约束见 [API 契约](API契约.md)。

## 1. 首页与身份

首页提供儿童和家长入口，统一进入 `/auth`。游客体验与正式账号分开：家长游客使用标明的示例；正式家长没有孩子时显示邀请码，没有作品时显示空状态。真实请求失败显示重试，不替换成演示数据。

家长邮箱注册 → 创建家庭与邀请码 → 儿童凭昵称、4 位创作码与邀请码加入。儿童昵称当前全局唯一。一个家庭可有多个孩子；尚无第二位家长加入已有家庭的界面。

## 2. 儿童小屋与画布

`/child` 是 Nilo 互动空间；`/child/create` 提供自由绘画和图形热身、画笔颜色/粗细、橡皮、撤销、清空及 PNG 下载。

点击完成时导出当前完整画面，发送 `POST /api/analyze`，带 `source: digital_canvas` 和本次图像的 `submissionKey`。请求中禁用绘画编辑。相同图像重试复用提交键；画面改变后使用新键。视觉识别失败允许重试，登录失效先刷新会话，不把正式作品当游客处理。

服务端校验并提取特征，按维度置信度过滤后生成描述反馈。正式儿童的原图、特征和反馈落库，成功返回 `analysisId`。游客不会产生家庭记录。

再画一点时仍识别新的完整快照，不把已擦掉的元素、旧的构图或估计擦除次数累加。草稿仅保留在当前账号的浏览器会话内，离开再返回可恢复；刷新页面或退出后不承诺保留。画布没有采集真实笔压或擦除操作次数。

## 3. 家长回看与解读

`/parent` 根据家庭与所选孩子读取历史。聚焦窗口和定时刷新获取新作品，切换孩子时忽略旧请求结果。

- 成长概览：近期作品与可核对的计数；AI 描述明确标注来源。
- 创作记录：显示全部分页历史，可进入 `/parent/archive` 完整成长档案。
- 完整解读：在概览展开后选择服务端作品，按 `analysisId` 生成或回看报告；不依赖儿童设备的 sessionStorage。生成/删除后刷新历史。
- 主题探索与时间轴：依据已保存创作和已有报告组织观察，不填补虚构的心理指标。
- AI 沟通助手：整理已有解读中的建议和提示卡；没有自由输入、多轮聊天能力。

基础解读由知识库和代码评分生成，可选模型补充说明。弱信号、冲突、信息不足与零命中分别处理，参考分值不能解释为实际心理概率。

## 4. 周报与月报

家长导航“周报与月报”可切换每周摘要、每月报告，刷新、分页并下载单份 JSON。摘要列出作品数、创作天数、已有解读数、其中信息不足数、常见元素与已有建议。来源作品编号保存在下载数据内。

按北京时间自然周（周一至周日）和自然月汇总，只为已结束且有作品的周期生成。正在进行的周期通过创作记录查看；没有摘要时解释原因。服务启动、每小时任务和页面访问均可补齐历史。切换孩子和报告类型时不显示上一份请求的数据。

## 5. 档案与家庭设置

完整成长档案可导出全部作品或本年成长册。产物为内嵌原图与已有解读的独立 HTML，可离线查看并通过浏览器打印成 PDF；图片读取失败会中止导出，未解读作品不会自动发起模型调用。

家庭设置可复制邀请码、填写孩子生日、设置本机头像和退出登录。即使没有孩子，也能进入账号设置。

单幅删除位于完整解读中，确认后删除原图、分析和解读，并使该孩子的周期摘要失效，后续按剩余记录重建。

“注销整个家庭”要求家长密码和输入“删除整个家庭”。成功后删除该家庭的账号、作品、报告并使所有设备会话失效；备份按保留周期清理。失败保留当前会话并显示原因。该动作不是退出登录，界面须展示其不可撤销范围。

## 6. 体验与计划

当前开放游客和正式家庭体验，显示实际可用功能。支付订阅不在本轮实现，不展示可支付按钮或声称已购买套餐。AI 请求仍受部署额度与限流约束。
