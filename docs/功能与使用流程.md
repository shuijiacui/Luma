# Luma 当前功能与使用流程

> 更新日期：2026 年 9 月 25 日。依据当前代码整理，包含虚线引导、明确指令直接修改、圈选与描画关联、原稿及协助记录保存。
> 本文说明已接入的功能、实际操作入口和使用条件；历史设计稿及后续商业计划不作为已上线功能。

Luma 将儿童创作与家长回顾连接起来：孩子在 Nilo 的陪伴下画画、保存和续画；家长查看孩子完成分析的作品，生成解读、获得沟通建议，并回顾一段时间内的创作。

## 1. 产品结构与入口

| 空间 | 主要用途 | 本地开发入口 |
| --- | --- | --- |
| 官网 | 品牌展示、中英文切换、订阅计划说明、双端登录入口 | `http://localhost:5173/` |
| 儿童端 | Nilo 小屋、绘画、共创、语音、历史图画 | `http://localhost:5175/` |
| 家长端 | 成长概览、创作记录、家庭设置、周报/月报、沟通建议 | `http://localhost:5174/` |

从官网点击“儿童端”或“家长端”，直接进入对应登录页面，不经过第二个首页。登录页提供“返回官网”；儿童小屋顶部品牌也可返回官网。

开发环境保留三个独立前端服务；生产可使用同一站点，也可配置不同的双端域名。具体地址以部署配置为准。

### 账号与游客体验

| 身份 | 如何进入 | 数据与能力 |
| --- | --- | --- |
| 正式家长 | 邮箱、密码登录；注册填写称呼、邮箱、密码 | 创建家庭、获取邀请码，管理同家庭多个孩子，查看真实记录 |
| 正式儿童 | 昵称、4 位数字创作码登录 | 使用家庭空间，保存作品到服务端，在其他设备登录后继续画 |
| 儿童游客 | 登录页选择游客体验 | 可以画画、保存到当前浏览器；AI 功能仍取决于服务配置，不写入正式家庭档案 |
| 家长游客 | 登录页选择游客体验 | 查看明确标识的演示家庭和示例记录，不代表真实孩子的数据 |

**首次创建家庭：**家长注册 → 在家庭设置复制邀请码 → 孩子在儿童端注册 → 填写邀请码、昵称和两次创作码 → 加入家庭。

一个家庭可关联多个孩子。当前儿童昵称要求唯一；尚未提供第二位家长加入已有家庭、找回密码和邮箱验证的完整流程。

## 2. 儿童端：从小屋到画布

### 2.1 Nilo 小屋

登录后进入 Nilo 的互动场景，主要入口如下。

| 位置 | 操作 | 结果 |
| --- | --- | --- |
| Nilo 角色 | 点击头、鼻子、手、肚子、尾巴或星星灯 | 出现相应角色动作、预设短句和音效 |
| “去画画”大门 | 点击开门 | 播放开门过渡，进入一张新的画布 |
| “历史图画 / 我的小画册”木板 | 点击木板 | 打开已保存作品，选择继续画 |
| 顶部声音按钮 | 开启或关闭 | 控制小屋互动声音 |
| 顶部问号 | 点击“怎么玩” | 查看或重新开始操作引导 |
| 顶部头像 | 点击设置 | 选择预设头像或上传图片 |
| “下次见” | 点击 | 退出儿童账号并返回登录页 |

**大门表示新建作品，会清掉上一张留在内存中的草稿。** 想继续旧画，应先保存，再从木板进入历史图画。

### 2.2 进入画布与模式选择

首次进入空白画布时，可选择：

- **我自己画：**孩子自主绘画，Nilo 绘画邀请、圈选协助修改按钮置灰且不可点击；不会点击后自动切换模式。语音聊天、声音开关和连续对话仍可使用。切到“和 Nilo 一起画”后恢复共创操作，原有笔迹保留。
- **和 Nilo 一起画：**孩子点击“轮到 Nilo”，Nilo 投影灰色虚线底图，孩子直接描画学习；语音绘画同样生成描摹底图。

当前界面提供这两种绘画模式，可在画布顶部随时切换。已有草稿和历史作品直接进入编辑，不强制重复欢迎流程。图形热身和工具引导都可主动使用。

### 2.3 画布工具与布局

| 区域 | 当前功能 |
| --- | --- |
| 顶部 | 返回小屋、两种模式切换、背景音乐、帮助、历史图画、下载、语言、头像；小屏部分操作收进“更多” |
| 左侧窄工具区 | 可收起的画笔工具、快捷颜色、完整调色盘、自选颜色、笔刷、橡皮、粗细滑条 |
| 中间画布 | 实际绘画区域；与周围控件留出间距 |
| 底部中间 | 换图形、清除图形、撤销、清空、保存、完成 |
| 底部 Nilo 区 | 圈选、交接绘画回合；麦克风、Nilo 声音、连续对话同排显示。有底图时提供带文字的“换个画法”和“清除底图” |

工具栏默认收起，开合状态按屏幕类型记忆。展开和收起占用相同的侧边空间，不改变画布的位置、尺寸和笔迹比例；左侧工具栏与调色盘不覆盖绘画区。Nilo 字幕可能短暂浮在画布边缘；底图直接拖动手柄移动、缩放，不再需要打开调整菜单。已有笔迹的作品在窗口变化时保持原有纵横比。

**绘画工具：**

- 5 种笔刷：圆头笔、铅笔、马克笔、蜡笔、星星笔，各有不同笔迹效果。
- 24 种预设颜色，另有系统颜色选择器可自选颜色。
- 1–32 的画笔粗细滑条，可逐级调整；不同笔刷的实际笔迹外观有所不同。
- 橡皮、最近操作撤销和清空。一次协助修改即使包含改色、移动等多个动作，也作为一次操作撤销。
- 6 种引导轮廓：半圆、圆形、三角形、星星、爱心、云朵。默认可自由画，点击“换图形”使用；“清除图形”只移除引导，不清空孩子的画。
- PNG 下载。引导轮廓和 Nilo 描摹底图不进入下载图像；孩子描出的线条会保留。

**背景音乐：**顶部可开关音乐、选择 5 首配乐并调节音量；语音期间会降低音乐音量，结束后恢复设置。背景音乐与 Nilo 说话的声音分别控制。

### 2.4 “保存”“完成”“下载”的区别

| 操作 | 实际作用 | 家长端是否新增创作记录 |
| --- | --- | --- |
| 保存 | 保存当前合成画面、笔迹文档和版本，供儿童历史图画续画；不调用识别模型 | **不会**，仅保存可编辑作品 |
| 完成 | 先保存；符合来源条件时再分析并给出描述性反馈。发生实际协助修改时保存创作过程，跳过自主特征分析 | 仅分析成功时新增或复用对应分析记录；共同修改的作品不会因此新增自主分析 |
| 下载 | 将当前已确认的画面导出为本地 PNG | 不会 |

“完成”后的反馈显示在画布的 Nilo 区域，不跳转到单独的结果页。孩子可以继续添画，修改后再次保存或完成。

模型暂时不可用时，已经成功保存的画不会因此丢失。来源不明、没有笔迹来源记录的旧图可以继续保存，但暂不生成新的成长分析。实际共同修改的作品会提示“这幅画包含共同修改，已保存创作过程。”；当前尚未实现针对这段过程的分析报告。

### 2.5 历史图画与续画

操作流程：**小屋木板或画布顶部“历史图画” → 选择作品 → 继续画 → 保存。**

- 列表显示预览和更新时间，支持“更多图画”分页加载。
- “画一幅新的”创建新画布。
- 正式账号从服务端读取作品；游客从当前浏览器读取。
- 新版作品保留原始笔迹、引导曝光及协助修改／撤销记录；旧文档已有的描画关联也会保留，重新打开后可继续选择和修改。只有 PNG、没有笔迹数据的旧作品可继续画，但不能精确编辑其中的独立对象。
- 同一作品继续保存会更新版本；出现其他设备已更新的冲突时，不直接覆盖对方版本。
- 当前儿童历史页没有重命名和删除作品按钮。

未保存草稿除内存状态外，还通过 `sessionStorage` 按账号和作品暂存在当前标签页。刷新后可以选择继续草稿，或明确丢弃草稿、打开已保存版本；笔迹、工具设置和虚线底图可恢复，录音、对话及未完成请求不恢复。暂存失败会提示先保存或下载。该机制不是云端自动保存，不保证关闭标签页或清除浏览器数据后还能恢复。游客**已保存**作品可在当前浏览器再次打开，但清除浏览器数据后会消失；不会自动迁入新注册家庭。

## 3. Nilo 合作共创与语音

### 3.1 一次完整的合作流程

1. 在顶部选择“和 Nilo 一起画”。
2. 孩子先画一些内容，也可以通过麦克风讲述想法，例如“这是去月球的飞船”。
3. 点击画布外的 Nilo 头像，表示“我画完了，轮到你”。**这一步不会开启麦克风。** Nilo 声音开启时，会播报回应，并保留文字。
4. Nilo 先观察整幅画，再检索相关知识与画法，自主选择相关的新事物、颜色、大小和位置。当前 v3 不再增加第二次模型语义复核，也不强制围绕最后一笔。
5. 点击后由模型从整幅画选择最相关的新主意，直接绘制投影，不再出现叶子／云朵选择，也不再用随机短线兜底。识图不确定和少量重叠不阻止想象性添画；位置优先选空白。大小由模型结合主体比例与空间决定，保持图形原比例并限制越界。自定义路径过于简单或无法解析时，优先使用模型自己选出的相关完整画法；网络或服务故障仍如实提示，保留已有画作。图案以灰色参考底图展示（SVG 虚线、PNG 浅灰图像），默认保留，可移动、缩放或整组清除。
6. SVG 用约 1.2 秒动画投射灰色虚线底图，PNG 显示浅灰参考图并可查看原图；无需接受或切换描画模式，孩子可直接画。新笔迹按孩子实际绘制保存，不会自动转成模型笔迹，也不会仅因靠近虚线就与底图关联。系统保留整幅作品曾显示引导的记录。
7. 点“清除底图”只移除整组参考，孩子描出的笔迹全部保留。保存和下载只包含真实笔迹及已执行修改，不包含参考底图；底图随当前标签页草稿暂存。动画期间开始描画会立即显示完整底图；尚未返回的请求会停止，避免迟到结果替换正在描的底图。
8. 需要修改自主创作时，点击底部“圈选”，圈住或点选真实笔迹，继续圈住可补选，点已选笔迹可取消。点“选好了”保留选区并返回绘画；“取消选中”清空选区。若刚才的语音正等待目标，选好后自动重放该指令一次，不必再说一遍。

点击和语音新增内容、改变造型的建议统一显示描摹底图，保留原画。拖左上角手柄移动参考，拖右下角手柄等比缩放；这些底图操作本身不会移动已有实线。底图操作提供“换一个”和“清除底图”。“换一个”打开按具体题材组织的素材面板，可查看不同画法、初级和中级 PNG，也可主动选择其他题材；已有笔迹保持不变。只有孩子实际点选并替换成功才保存画风偏好，按账号在当前浏览器保留最近 32 条，访客只保留当前会话。语音“换个画法”仍优先为当前物体切换造型或细节，保留合适的摆放和其他组合图案；自由绘制的自定义物体可向模型请求同一物体的新画法。请求失败或返回其他物体时保留原底图，不偷偷更换题材。图案内部不拦截画笔，孩子自行选择实际颜色、笔刷和粗细。需要修改画好的内容时先圈选真实笔迹，再提出改色、移动等要求。旧文档已有完整关联组时仍支持参考同步调整；新笔迹不会推测归属。撤销相关修改会移除可能错位的底图，保留恢复后的真实画面。

### 3.2 当前共创能力

| 能力 | 当前实现 |
| --- | --- |
| 理解上下文 | 同时看已确认全图和最新绘画区域的放大图，结合画布尺寸、最近笔迹、作者边界及孩子的话；局部坐标映射回原画布 |
| 绘画知识库 | 36 个主题条目、37 类 73 张参考、22 组主题添画步骤，以及 6 类兼容绘画技巧；330 份审核可用 SVG 与 368 张独立 PNG；新增 334 张 PNG 为 167 个具体题材各配一张初级和中级参考，涵盖人物、建筑、植物、风景和生活物件。Nilo 根据孩子的画自动选择可爱、插画或观察线描，孩子不需知道风格名称；可说“圆一点”“细节多一点”“像真的一样”调整底图。不是模型训练 |
| 不知道物体名字 | 模型可结合整体氛围提出独立的新事物，不因低置信度停止；不宣称猜测就是孩子的意思 |
| 一次能画多少 | 一次一个可辨认的小主意，可为原有细节，也可为旁边的独立事物。完整自定义物体最多 24 条路径、96 个命令；细节仍最多 8 条。底图整组移动、缩放和清除 |
| 可用内容 | 普通语音保留 21 种基础模板及自定义线稿；点击和已有画面的新绘画请求使用 v3：模型选主意、颜色和比例，程序生成描摹底图。知识库外仍可生成自定义物体，相关性与画法质量仍取决于模型 |
| 颜色 | SVG 底图显示细灰虚线，PNG 显示浅灰参考图；孩子选择描画颜色；明确要求修改已有选区时可直接改色，保留线条和笔刷 |
| 自定义复杂度 | 普通绘画每个物体最多 24 条路径、每轮最多 4 个元素及 64 条笔迹；点击接力只补一个部分，通常 1–4 条、必要时最多 8 条短路径，超过 4 条限制为画布 6% 以内。复杂物体优先保留轮廓与关键细节 |
| 比例控制 | 根据实际画布宽高修正物体比例，结合主体框限制尺寸和相对位置 |
| 避让已有内容 | 校验实际笔迹和笔刷宽度；必要时在附近微调或等比缩小，不把内容搬到无关角落 |
| 描摹学习 | 直接参照虚线绘画，无需切换模式；新笔迹保留孩子作者身份，不自动关联底图。保留整幅作品的引导曝光记录，不能仅因实际执笔者是孩子就视作完全自主创作 |
| 基础修改 | 对已选真实笔迹或可靠命名对象，明确的改色、移动、等比缩放和定位直接执行；多个动作先完整校验，再原子提交，可一次撤销。不会顺便修圆、重描或美化 |
| 孩子的决定权 | 新增与造型变化始终先给虚线参考，不替换原画；“蓝色会不会更好”等建议询问不执行修改。缺少明确目标时先选择，不猜测最后一笔就是整个对象 |
| 不合适时 | 完整多笔画场景提供两个可点选的本地小主意，以描摹底图展示；不自动复制最后一笔。画布已满时提示撤销或换纸。普通语音请求仍可询问具体想法 |
| 简短记忆 | 按孩子和作品记录故事主题、近期接受/拒绝的模板及自定义物体名称；拒绝一种物体不会关闭其他自定义创作。可说“忘掉这个故事”清除，不会清空画作 |

可以通过麦克风提出“画一个机器人”“帮我添一只恐龙”等要求，模型会尝试生成相应线稿。已有基础模板仍用于适合的小元素；模板与自定义物体可以组合。自定义内容同样使用灰色虚线，可移动、等比缩放、整组清除及随草稿恢复；实际画笔和颜色由孩子自己选择。

这仍是一套有复杂度上限的线稿共创功能，不是写实图片生成器。超出复杂度、几何无效或没有合适位置的方案不会落笔；不能保证任意物体都准确可辨。对象理解和建议质量取决于配置的视觉/语言模型。

### 3.3 和 Nilo 说话

1. 点击底部麦克风，按浏览器提示允许收音。
2. 说出故事或要求，例如“帮我的船加一点浪花”。
3. 点“说完了”，或等待本段识别结束；识别出的内容在底部显示。
4. Nilo 根据内容回应。一起画模式下，新增图案或造型变化给出虚线底图；目标明确的基础修改直接执行，并给出文字与语音反馈。声音关闭时只显示文字。
5. 需要持续交流时，主动开启“连续对话”；不再需要时点击停止。麦克风、Nilo 声音和连续对话直接同排显示，无需展开声音菜单。

| 控件或说法 | 效果 |
| --- | --- |
| 麦克风 | 开始说话、结束本段，或打断正在播报的内容 |
| Nilo 声音按钮 | 控制回答是否播报；关闭声音不等于关闭麦克风能力 |
| 连续对话按钮 | 主动开启或结束连续收听与回应，不会默认开启 |
| “留下来” / “keep it” | 底图保持可描画，不转成模型笔迹 |
| “清除底图”“先不要” / “clear guide”“cancel” | 清除当前底图，保留孩子描出的线条 |
| “换一个”“换个画法” / “another one”“another style” | 有底图时换同一物体的其他画法；素材画法本地轮换，自定义图形可能需要模型请求，保留位置、大小和颜色 |
| “小一点”“往左”“换成蓝色” | 优先操作明确选区；没有选区时结合可靠对象关联或当前底图判断，无法确定就请孩子选择 |
| “把这个太阳改成蓝色，再小一点” | 明确选中后一次完成改色与等比缩放，不要求重新描画或反复确认 |
| “放到左上角” | 根据目标尺寸计算定位，完整放入画布；超出能力或无效时不执行部分修改 |
| “给这个人加帽子”“换一种造型” | 提供新增或替代造型的虚线参考，保留原画，不提交模型实线 |
| “恢复刚才的样子” | 撤销最近可撤销的协助修改，恢复之前画面，保留修改来源记录 |
| “蓝色会不会更好” | 回应建议，不直接修改 |
| “停止” / “stop” | 停止当前交流和待处理提案 |

新底图无需确认，也不会因“留下来”“好看”“我喜欢”等话语转成作品笔迹。真实笔迹的基础修改由孩子的明确指令授权，不另设预览确认；暂未开放直接删除选区或自动重画轮廓。画布没有文字输入框。

底部“圈选”选择整条笔迹，不会仅凭包围框重叠就选中无关线条；自由涂鸦尚不保证自动拆成语义对象。已明确关联的描画和旧版 Nilo 对象可按名称或候选选择。来源、分组和协助历史随可编辑作品保存，只有 PNG 的旧画不能恢复为独立对象。

孩子说“改成蓝色”但目标不清楚时，系统暂存这次要求，打开选择入口；补选过程中不会执行，点“选好了”才重放一次。按 Escape 退出会取消等待中的指令。改口按完整句子理解，不简单使用第一个或最后一个颜色；含义仍不明确时先询问。修改执行由本地画布完成，简单明确指令可本地理解；复杂句子的理解和语音识别仍可能调用现有模型／服务。

实际协助修改不覆盖原始点位、颜色和笔刷数据，而是追加 `assist` 记录；撤销协助追加 `assist-revert`。显示及导出应用有效修改，原稿与历史保留。描画笔迹仍属于孩子，但关联引导来源；创作会话接受过引导也单独标记。共同修改后继续创作的画面不能通过机械剔除修改恢复成“独立原画”，因此当前只保存过程，跳过自主特征分析，尚不生成过程分析报告。

### 3.4 语音与调用条件

- 当前默认使用浏览器识别和朗读，已移除本地双模型比较工具，不需要另启 Python 语音服务。断句、改口和上下文理解仍由现有整句处理链路完成，不因移除实验模型而删除。
- 浏览器朗读优先选择设备可用的同语种童声，没有时选择轻柔音色；效果取决于设备，不能保证每台设备都有童声。文字回复与语音保留同一内容，静音时仍显示文字。
- 回复优先回应孩子当前的话、选择或困难，鼓励尝试，不评价天赋或要求画得像。底图出现时保留模型针对这次主意的简短回应；调整、修改、清除等反馈使用多种短句，避免连续重复。最近三次措辞仅用于会话内避免重复，不当成孩子的意图或绘画证据；不增加额外模型请求。
- 云端识别、合成可通过 `VOICE_ASR_ENABLED`、`VOICE_TTS_ENABLED` 独立启用，示例均为 `false`。可选云端 Mochi 音色需要单独配置 `VOICE_*` 服务；不会自动复用绘画模型密钥，也不默认启用云语音。
- 生产环境麦克风需要安全访问环境及用户授权；不支持识别、拒绝授权或连接失败时，会提示原因，仍可用按钮画画和确认。
- 单段语音最多 20 秒；连续会话最多 5 分钟或 12 轮。离开页面、停止或异常会终止当前录音/播放。
- 本项目不持久保存原始录音或完整转写；供应商侧的数据处理取决于所配置服务。
- 点击接力只发起一次 HTTP 请求，前端等待最多 16 秒，服务端默认预算 14 秒；包含一次短观察、规划与复核；正常三次模型调用，最多一次观察、两次规划、两次复核。局部图和按需检索的绘画资料会增加输入用量，本地接笔不新增模型调用。普通语音绘画输出上限 3600 tokens，纯对话 1800 tokens；完整预算见 [Nilo API](../server/NILO_API.md)。上限不是固定消耗，移动、缩放、换色和确认仍在本地完成。
- 默认按 IP 分别限制绘画 24 次/分钟、识别 36 次/分钟、播报 36 次/分钟，另受全局限流保护。这不是一幅画的总笔数限制，也不是付费套餐权益。

## 4. 家长端：查看、理解与回顾

### 4.1 顶部与导航

家长端顶部集中孩子切换、语言、通知和家长头像等入口；家长头像在通知右侧。电脑端保留侧边导航和桌面内容区，手机端使用顶部信息区与底部导航，不把整个桌面页面简单缩成长图。

主要栏目是：**成长概览、创作记录、家庭设置、周报与月报、沟通建议。** 沟通建议页标题为“AI 沟通助手”。

正式家长没有孩子时显示邀请码与加入提示；没有作品时显示真实空状态；网络错误显示重试。只有游客体验使用演示数据。

### 4.2 成长概览

概览用于查看当前孩子的创作情况，包括近期创作数量、周期报告状态、本周摘要及最近作品等。旧心理趋势功能已停用。

“本周成长摘要”的“查看详情”进入创作记录；电脑端“最近一幅作品”右上日期或箭头用于展开完整解读。主题探索和时间轴位于创作记录栏目。家长切换孩子后，作品、报告和请求状态随之切换，不应混入上一个孩子的数据。

概览中的“本月报告”状态卡目前根据是否存在单幅解读显示“已生成”，并不代表自然月摘要已经生成；实际周期报告以“周报与月报”栏目为准。

数量与趋势来自已有记录，不代表系统持续监测孩子，也不应理解为心理诊断。

### 4.3 单幅作品解读

**电脑端流程：成长概览 → 最近一幅作品右上日期或箭头 → 完整解读 → 选择孩子完成分析的作品 → 生成或回看报告。**

当前报告能力包括：

- 展示作品、画面描述和已识别特征。
- 根据 5–12 岁画面观察词表展示可见元素、颜色和可验证位置，不从单幅画推断心理状态。
- 按 5–7、8–9、10–12 岁调整开放式亲子沟通问题与 Nilo 共创对话措辞；生日未知时使用通用问题。年龄不改变可见证据、画作含义或可画题材；看不清或词表没有覆盖时明确说明不足。
- 保存生成结果，之后可按作品记录回看，不依赖儿童设备仍在线。
- 新报告展示已核对文献的一般研究背景和适用局限，不调用未经审核的 PDF 检索、联网建议或情绪评分；历史旧版报告保留版本标记供回看。
- 删除所选分析记录，并更新受其影响的周期摘要。

**来源区分：**共创时，Nilo 规划会看当前完整画面；满足来源条件的分析保留引导／共创说明。发生实际协助修改时，儿童端保存修改后作品和创作过程，跳过自主特征分析，不会把机械去除修改后的图像冒充独立创作；当前没有过程分析报告。家长已有分析记录与儿童可编辑作品分别保存。

**删除范围：**当前“删除所选画作”删除的是家长侧分析记录及其图片副本，不同时删除儿童历史图画中的可编辑原稿。两者是不同记录。

### 4.4 创作记录、主题和时间轴

| 功能 | 用途 |
| --- | --- |
| 创作记录 | 按月份浏览当前孩子完成分析的作品和日期；卡片以展示为主，没有独立作品详情跳转 |
| 主题探索 | 根据作品中出现的元素与已有记录组织主题观察 |
| 成长时间轴 | 可切换 30 / 90 / 180 天，按时间回顾作品数量和主题 |
| 趋势摘要 | 心理趋势已停用；按日期回看每幅作品的可见观察 |

只点“保存”、尚未完成分析的儿童作品不会出现在这些家长分析视图中。

### 4.5 周报与月报

操作流程：**进入“周报与月报” → 选择每周或每月 → 浏览摘要 → 刷新或通过上一页 / 下一页浏览 → 按需下载 JSON。**

摘要包括作品数、创作天数、已有解读数、信息不足的解读数量、常见元素、已有建议及来源记录。

- 按北京时间的自然周（周一至周日）和自然月统计。
- 只为**已经结束且有记录**的周期生成摘要；当天新建家庭不会出现虚构历史报告。
- 进行中的周期可先查看创作记录。
- 服务启动、定时任务和页面读取可补齐已结束周期。
- 汇总已有数据，不额外调用模型；删除分析或修改解读后会重新汇总相关内容。

### 4.6 AI 沟通助手

家长端助手以**日常聊天为主，作品记忆和建议卡片为辅**。可以聊生活里不知道如何开口的场景，不需要先选择作品。输入后由家长确认发送；快捷话题和“聊聊这幅画”只填写草稿，不自动发送。不单独增加语音转写，可使用设备键盘自带的听写。

作品记忆读取孩子最近 50 条分析里的有效画面观察，相关时最多引用 4 件；不读取心理评分、不把机器描述当孩子原话。回复引用作品时可点击回看。聊天按孩子和家长账号保存最近 60 轮，可随时清空；清空不会删除孩子作品。模型每轮使用最近 12 轮内的有限上下文，因此并非永久记住所有生活经历。家长对画面的纠正留在近期聊天里，不修改原始分析。

“从画作找个话题”按需展开建议卡片。服务端从最近 30 条新版观察报告中优先选择最多两幅内容不同的作品；不足时可以只展示一张或暂不展示。流程：孩子完成分析 → 家长生成作品解读 → 打开建议 → 选一句开场白 → 按需展开接话方式。点击缩略图可以回看来源。

配置文本模型后，服务端按可见事实和年龄段，一次请求生成最多两张卡片的措辞。来源、日期、观察事实由服务端确定，模型不能改写；输出经过结构、来源 ID、禁用措辞和词表检查，未通过、超时或模型未配置时使用分龄模板。这些检查不是对所有语义错误的保证，模型内容仍需真实样本评估。按孩子、语言、来源和生成版本缓存，刷新不重复调用；新来源、年龄段或模型配置变化后更新。缓存随来源作品删除、家庭注销清除。

页面只保留一次“AI 沟通助手”标题，整体固定在一屏内。桌面对话在左、作品在右；手机作品区默认收起。作品区域和聊天记录内部滚动，输入框固定，默认约 42px，输入多行时适当增高。正式家长聊天复用已有文本模型配置，不将密钥放入前端；失败保留输入并允许重试，不回退到游客脚本。

游客可直接输入体验预写的本地多轮对话，覆盖发脾气后的修复、学校沟通、作业、手机使用和示例画作。画作缩略图、来源预览、沟通卡片与“聊聊这幅画”均可用。游客聊天与作品资料不请求 API，不显示接口配置提示。聊天区左上角「历史记录」打开抽屉，按最近聊天时间显示各段的第一句话、最后回复摘要与日期，可继续聊或确认删除；右上角「新对话」保留旧记录并打开空白对话。记录使用当前浏览器 localStorage，按孩子与语言隔离，关闭页面后仍可回看；最多 30 段，每段保留最近 30 轮。旧的当前标签页单段记录会自动迁入。正式账号仍使用服务端单段会话，不读取游客历史。该功能是有限脚本演示，不代表模型对任意问题的实际效果。逐句操作见 [家长沟通助手演示剧本](家长沟通助手演示剧本.md)。

演示顺序可用：“刚才没忍住，冲孩子发了脾气” → “可每次都要我调整，我也很累” → “那我怎么跟他说？” → “这话我说不出口”。画作场景可用：“想聊聊孩子最近的画” → 点击作品或输入“聊聊那幅小船” → “他说小船不想回家” → “这是不是说明他很孤独？”；点击“清空聊天”可回到起点。

### 4.7 家庭设置与头像

- 复制家庭邀请码，让其他孩子注册加入。
- 查看关联孩子，修改孩子出生日期；年龄条件用于后续报告，不凭画面猜年龄。
- 在顶部更换家长头像，可选预设或上传图片。设置页退出登录区域的头像只展示，并与顶部同步。
- 退出登录位于设置的上部。退出账号和注销家庭是两种不同操作。
- 正式家庭可以从设置中重新播放新手引导。
- 注销整个家庭需要家长密码及指定确认文字；成功后清理在线家庭数据并撤销相关会话。

头像目前是当前浏览器的本地设置，不是云端头像同步。备份文件、用户已下载的副本和外部服务留存不会因家庭注销而同时消失。

### 4.8 成长档案与导出

完整成长档案页面支持按月份查看，以及导出全部或本年成长册。

- 导出格式为内嵌原图和已有解读的独立 HTML，离线打开后可用浏览器打印成 PDF。
- 未生成解读的记录不会因为导出而自动批量调用模型。
- 图片读取失败时会中止导出并提示，避免生成缺图档案。
- 周报/月报另支持 JSON 下载。

**当前入口限制：**档案路由 `/parent/archive` 已实现，但主界面尚缺少直接跳转按钮。登录家长端后，可在家长端地址后输入该路径，例如 `http://localhost:5174/parent/archive`。

## 5. 推荐的完整使用流程

### 流程 A：快速体验，不创建家庭

1. 官网进入儿童端，选择游客体验。
2. 在小屋点击 Nilo，打开大门。
3. 选择自己画或一起画，试用笔刷、颜色、图形轮廓和背景音乐。
4. 主动点击 Nilo 获取参考底图，移动、缩放或从“换一个”选择其他素材，再自行描画或清除底图。
5. 保存到本机，或下载 PNG；进入历史图画确认可继续画。
6. 返回官网，进入家长游客空间，查看带演示标识的概览与建议。

儿童游客画作不会自动进入家长演示家庭；这两个体验空间不是绑定家庭。

### 流程 B：真实家庭日常使用

1. 家长注册，获取家庭邀请码。
2. 孩子用邀请码注册昵称与创作码。
3. 家长在家庭设置填写孩子出生日期，并选中该孩子。
4. 孩子进入小屋，新建画作，选择模式并创作。
5. 需要 Nilo 帮忙时，通过头像交接回合，或使用麦克风提出要求；新图案以灰色虚线底图展示，孩子可直接描画。
6. 中途点“保存”；想让家长回顾时，点“完成”，等待分析成功。
7. 家长查看新增记录，在电脑端点击最近作品右上日期或箭头展开完整解读，生成或回看单幅报告。
8. 参考沟通建议和主题记录，与孩子聊画里的故事。
9. 自然周或月结束后查看周期摘要，必要时导出档案。

### 流程 C：继续完成旧画

1. 儿童小屋点击“历史图画”木板。
2. 选择已保存作品进入画布。
3. 继续绘画、撤销笔迹或邀请 Nilo 共创。
4. 点“保存”更新可编辑作品；需要产生新的家长分析记录时，再点“完成”。

## 6. 中英文与设备适配

| 项目 | 当前行为 |
| --- | --- |
| 中英文切换 | 通过页面顶部语言按钮即时切换，不清空画布或表单 |
| 偏好记忆 | 保存在当前浏览器、当前站点；同源标签页同步，独立域名或不同端口不保证共享 |
| 内容翻译 | 界面、规则文案和新报告可按语言展示；用户昵称、作品原文和历史自由文本不自动翻译 |
| 官网艺术英文 | 品牌标语保留英文设计 |
| 家长电脑端 | 侧边导航与桌面排版；内容较多的区域按页面设计滚动 |
| 家长手机端 | 顶部信息区、底部导航和紧凑卡片；与桌面布局分别适配 |
| 儿童手机端 | 静默尝试锁定横屏，必要时在首次点击后尝试全屏；不显示旋转引导阻断层 |
| 平板与电脑儿童端 | 不执行手机方向锁定；画布根据可用空间适配 |

网页不能保证所有手机浏览器都允许方向锁定；如果浏览器拒绝或不支持，页面继续可用，不代表设备一定会物理旋转。

**当前手机家长端限制：**最近作品卡及完整解读入口仅在桌面宽度显示，手机常规导航尚缺少生成/删除单幅解读的入口。现阶段这些操作应使用电脑端。历史列表、长报告和档案也并非所有屏幕下都无需滚动。

## 7. AI、数据与运行支持

### 7.1 AI 功能分别依赖什么

| 能力 | 支持方式 | 是否需要额外配置 |
| --- | --- | --- |
| 小屋互动、基本绘画、保存与续画 | 前端交互及作品接口 | 不需要 AI 模型 |
| Nilo 看画共创 | 视觉/文本模型产生受约束提案，前端校验和绘制 | 需要可用的 `LLM_*` 服务 |
| “完成”后的画面描述 | 视觉提取客观特征，再生成描述性反馈 | 需要视觉服务 |
| 家长画面观察 | 读取孩子笔迹的已识别特征、画面观察词表与开放问题 | 已有有效分析时，不再调用语言模型 |
| 文献背景 | 已核对的研究卡片与原文链接 | 新报告展示一般研究背景，不解释个体画作 |
| 心理文献 RAG | PDF 索引、Python、Chroma 和独立 embedding 配置 | 保留为离线研究工具；未经审核片段不进入新报告 |
| 云端语音 | ASR 识别和 TTS 合成 | 单独配置 `VOICE_*` |
| 周报/月报 | 汇总已有记录 | 不新增模型调用 |

新报告保留 OBS 条目编号和知识版本，数字画板没有实际采集笔压等证据时不推断相关行为。旧版心理规则与分值只作为历史档案保存，不用于新家长报告。

### 7.2 数据保存与权限

- 正式家庭的账号、作品、分析和报告保存在服务端；图片通过受保护接口访问。
- 家长只查看同家庭孩子的数据，儿童账号不能获取家长完整报告及趋势。
- 可编辑作品与家长分析记录分别保存；保存、分析、删除的作用范围见前文。
- 语音、共创故事与头像不是无限云端记忆：完整对话不持久保存，故事摘要和头像等偏好主要保存在当前浏览器。
- 服务端提供备份、图片完整性审计及恢复到新目录的脚本；这些是运维工具，不是用户界面按钮。

### 7.3 本地启动

使用 Node.js 24，在仓库根目录安装依赖：

```bash
npm --prefix server ci
npm --prefix frontend ci
```

将 `server/.env.example` 复制为 `server/.env`，按实际服务填写配置。密钥仅保存在服务端；示例模型名不保证在所有账号中可用。

终端一启动后端：

```bash
npm --prefix server run dev
```

终端二同时启动官网、家长端和儿童端：

```bash
npm --prefix frontend run dev
```

后端默认 `3001`，三个前端默认 `5173 / 5174 / 5175`。前端启动命令不包含后端；只启动官网进程不足以保证独立端入口和 API 都可用。

生产部署、跨域地址、语音和文献索引配置详见文末链接。
