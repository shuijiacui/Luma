# Luma 当前功能与使用流程

> 更新日期：2026 年 9 月 18 日。依据当前代码整理，包含自定义线稿共创能力。
> 本文说明已接入的功能、实际操作入口和使用条件；历史设计稿及后续商业计划不作为已上线功能。

Luma 将儿童创作与家长回顾连接起来：孩子在 Nilo 的陪伴下画画、保存和续画；家长查看孩子完成分析的作品，生成解读、获得沟通建议，并回顾一段时间内的创作。

## 1. 产品结构与入口

| 空间 | 主要用途 | 本地开发入口 |
| --- | --- | --- |
| 官网 | 品牌展示、中英文切换、订阅计划说明、双端登录入口 | `http://localhost:5173/` |
| 儿童端 | Nilo 小屋、绘画、共创、语音、历史图画 | `http://localhost:5175/` |
| 家长端 | 成长概览、创作记录、家庭设置、周报/月报、沟通建议 | `http://localhost:5174/` |

从官网点击“儿童端”或“家长端”，直接进入对应登录页面，不经过第二个首页。登录页提供“返回官网”；儿童小屋顶部品牌也可返回官网。

开发环境保留三个独立前端服务；生产可使用同一站点，也可配置不同的双端域名。具体地址以部署配置为准。

### 账号与游客体验

| 身份 | 如何进入 | 数据与能力 |
| --- | --- | --- |
| 正式家长 | 邮箱、密码登录；注册填写称呼、邮箱、密码 | 创建家庭、获取邀请码，管理同家庭多个孩子，查看真实记录 |
| 正式儿童 | 昵称、4 位数字创作码登录 | 使用家庭空间，保存作品到服务端，在其他设备登录后继续画 |
| 儿童游客 | 登录页选择游客体验 | 可以画画、保存到当前浏览器；AI 功能仍取决于服务配置，不写入正式家庭档案 |
| 家长游客 | 登录页选择游客体验 | 查看明确标识的演示家庭和示例记录，不代表真实孩子的数据 |

**首次创建家庭：**家长注册 → 在家庭设置复制邀请码 → 孩子在儿童端注册 → 填写邀请码、昵称和两次创作码 → 加入家庭。

一个家庭可关联多个孩子。当前儿童昵称要求唯一；尚未提供第二位家长加入已有家庭、找回密码和邮箱验证的完整流程。

## 2. 儿童端：从小屋到画布

### 2.1 Nilo 小屋

登录后进入 Nilo 的互动场景，主要入口如下。

| 位置 | 操作 | 结果 |
| --- | --- | --- |
| Nilo 角色 | 点击头、鼻子、手、肚子、尾巴或星星灯 | 出现相应角色动作、预设短句和音效 |
| “去画画”大门 | 点击开门 | 播放开门过渡，进入一张新的画布 |
| “历史图画 / 我的小画册”木板 | 点击木板 | 打开已保存作品，选择继续画 |
| 顶部声音按钮 | 开启或关闭 | 控制小屋互动声音 |
| 顶部问号 | 点击“怎么玩” | 查看或重新开始操作引导 |
| 顶部头像 | 点击设置 | 选择预设头像或上传图片 |
| “下次见” | 点击 | 退出儿童账号并返回登录页 |

**大门表示新建作品，会清掉上一张留在内存中的草稿。** 想继续旧画，应先保存，再从木板进入历史图画。

### 2.2 进入画布与模式选择

首次进入空白画布时，可选择：

- **我自己画：**孩子自主绘画，Nilo 不接受共创落笔邀请；语音交流与绘画模式独立。
- **和 Nilo 一起画：**孩子主动把回合交给 Nilo，让它提出待确认的绘画内容。

当前界面提供这两种绘画模式，可在画布顶部随时切换。已有草稿和历史作品直接进入编辑，不强制重复欢迎流程。图形热身和工具引导都可主动使用。

### 2.3 画布工具与布局

| 区域 | 当前功能 |
| --- | --- |
| 顶部 | 返回小屋、两种模式切换、背景音乐、帮助、历史图画、下载、语言、头像；小屏部分操作收进“更多” |
| 左侧窄工具区 | 可收起的画笔工具、快捷颜色、完整调色盘、自选颜色、笔刷、橡皮、粗细滑条 |
| 中间画布 | 实际绘画区域；与周围控件留出间距 |
| 底部中间 | 换图形、清除图形、撤销、清空、保存、完成 |
| 底部 Nilo 区 | 交接绘画回合、麦克风、Nilo 声音、连续对话，以及投影确认和调整 |

工具栏默认收起，开合状态按屏幕类型记忆。展开和收起占用相同的侧边空间，不改变画布的位置、尺寸和笔迹比例；左侧工具栏与调色盘不覆盖绘画区。Nilo 字幕和临时调整条可能短暂浮在画布边缘。已有笔迹的作品在窗口变化时保持原有纵横比。

**绘画工具：**

- 5 种笔刷：圆头笔、铅笔、马克笔、蜡笔、星星笔，各有不同笔迹效果。
- 24 种预设颜色，另有系统颜色选择器可自选颜色。
- 1–32 的画笔粗细滑条，可逐级调整；不同笔刷的实际笔迹外观有所不同。
- 橡皮、儿童笔迹撤销、清空，以及单独的“Nilo 创作撤销”。
- 6 种引导轮廓：半圆、圆形、三角形、星星、爱心、云朵。默认可自由画，点击“换图形”使用；“清除图形”只移除引导，不清空孩子的画。
- PNG 下载。引导轮廓和未经确认的 Nilo 投影不进入下载图像。

**背景音乐：**顶部可开关音乐、选择 5 首配乐并调节音量；语音期间会降低音乐音量，结束后恢复设置。背景音乐与 Nilo 说话的声音分别控制。

### 2.4 “保存”“完成”“下载”的区别

| 操作 | 实际作用 | 家长端是否新增创作记录 |
| --- | --- | --- |
| 保存 | 保存当前合成画面、笔迹文档和版本，供儿童历史图画续画；不调用识别模型 | **不会**，仅保存可编辑作品 |
| 完成 | 先保存，再提交孩子自己绘制的部分进行分析；成功后给出描述性反馈，仍留在画布 | 正式儿童账号分析成功后会新增或复用对应分析记录 |
| 下载 | 将当前已确认的画面导出为本地 PNG | 不会 |

“完成”后的反馈显示在画布的 Nilo 区域，不跳转到单独的结果页。孩子可以继续添画，修改后再次保存或完成。

模型暂时不可用时，已经成功保存的画不会因此丢失。来源不明、没有笔迹来源记录的旧图可以继续保存，但暂不生成新的成长分析。

### 2.5 历史图画与续画

操作流程：**小屋木板或画布顶部“历史图画” → 选择作品 → 继续画 → 保存。**

- 列表显示预览和更新时间，支持“更多图画”分页加载。
- “画一幅新的”创建新画布。
- 正式账号从服务端读取作品；游客从当前浏览器读取。
- 新版作品保留儿童和 Nilo 的笔迹来源及撤销分组，重新打开后仍可分别撤销。
- 同一作品继续保存会更新版本；出现其他设备已更新的冲突时，不直接覆盖对方版本。
- 当前儿童历史页没有重命名和删除作品按钮。

未保存草稿只在当前页面会话的内存中保留，不承诺刷新、退出或切换账号后恢复。游客**已保存**作品可在当前浏览器再次打开，但清除浏览器数据后会消失；不会自动迁入新注册家庭。

## 3. Nilo 合作共创与语音

### 3.1 一次完整的合作流程

1. 在顶部选择“和 Nilo 一起画”。
2. 孩子先画一些内容，也可以通过麦克风讲述想法，例如“这是去月球的飞船”。
3. 点击画布外的 Nilo 头像，表示“我画完了，轮到你”。**这一步不会开启麦克风或自动朗读。**
4. Nilo 参考已确认画面、孩子的话、近期笔迹和前面的共创内容，提出一组相关的小主意。
5. 内容先投影在原画布上，尚未加入作品。
6. 孩子选择“留下来”“换一个”“调整”或“先不要”。
7. 确认后整组落笔，再由孩子继续画；不满意可一次撤销该组 Nilo 内容。

投影可以整组移动、放大、缩小和换色。普通调整在本地完成，不额外请求模型。孩子在投影期间继续落笔、切换作品或取消，会使旧投影失效。

### 3.2 当前共创能力

| 能力 | 当前实现 |
| --- | --- |
| 理解上下文 | 使用缩小后的已确认合成图、画布尺寸、最近笔迹、作者边界摘要和有限对话上下文 |
| 一次能画多少 | 按画面需要提出 1–4 个相关元素，作为同一组确认；不是每次必须画满 4 个 |
| 可用内容 | 21 种基础模板，以及模型规划的自定义线稿；模板之外的物体可用直线、曲线、椭圆组成轮廓与细节，不再受固定物体清单限制 |
| 自定义复杂度 | 每个物体最多 24 条路径；每轮最多 4 个元素、64 条笔迹，整组确认。复杂物体优先保留可识别的轮廓和关键细节 |
| 比例控制 | 根据实际画布宽高修正物体比例，结合主体框限制尺寸和相对位置 |
| 避让已有内容 | 校验实际笔迹和笔刷宽度；必要时在附近微调或等比缩小，不把内容搬到无关角落 |
| 画风匹配 | 默认沿用孩子最近一笔的笔刷、颜色和粗细；预览和确认使用同一套绘制路径与笔刷 |
| 孩子的决定权 | 模型只能提案，不能自行确认、删除原画或把未确认投影保存进去 |
| 不合适时 | 询问具体想法、提示调整或说明连接问题，不随机填入无关形状 |
| 简短记忆 | 按孩子和作品记录故事主题、近期接受/拒绝的模板及自定义物体名称；拒绝一种物体不会关闭其他自定义创作。可说“忘掉这个故事”清除，不会清空画作 |

可以通过麦克风提出“画一个机器人”“帮我添一只恐龙”等要求，模型会尝试生成相应线稿。已有基础模板仍用于适合的小元素；模板与自定义物体可以组合。预览与最终笔迹使用相同的儿童画笔，自定义内容同样支持移动、等比缩放、换色、保存和整组撤销。

这仍是一套有复杂度上限的线稿共创功能，不是写实图片生成器。超出复杂度、几何无效或没有合适位置的方案不会落笔；不能保证任意物体都准确可辨。对象理解和建议质量取决于配置的视觉/语言模型。

### 3.3 和 Nilo 说话

1. 点击底部麦克风，按浏览器提示允许收音。
2. 说出故事或要求，例如“帮我的船加一点浪花”。
3. 点“说完了”，或等待本段识别结束；识别出的内容在底部显示。
4. Nilo 根据内容回应。一起画模式下，绘画请求可以产生投影；确认步骤仍然保留。
5. 需要持续交流时，主动开启“连续对话”；不再需要时点击停止。

| 控件或说法 | 效果 |
| --- | --- |
| 麦克风 | 开始说话、结束本段，或打断正在播报的内容 |
| Nilo 声音按钮 | 控制回答是否播报；关闭声音不等于关闭麦克风能力 |
| 连续对话按钮 | 主动开启或结束连续收听与回应，不会默认开启 |
| “留下来” / “keep it” | 接受当前投影 |
| “先不要” / “cancel” | 取消当前投影 |
| “换一个” / “another one” | 请求其他想法；可能需要再次调用模型 |
| “小一点”“往左”“换成蓝色” | 对当前投影进行本地调整 |
| “停止” / “stop” | 停止当前交流和待处理提案 |

只有明确的完整确认指令才会落笔；“好看”“我喜欢”、否定句或问题句不视为确认。画布没有文字输入框。

### 3.4 语音与调用条件

- 云端识别、合成需要单独配置 `VOICE_*` 服务；不会自动复用绘画模型密钥。
- 默认示例接入阿里百炼 ASR/TTS，配置的默认音色为 Mochi。云端未配置时，尝试使用浏览器识别和系统音色，效果取决于设备，不能保证每台设备都有童声。
- 生产环境麦克风需要安全访问环境及用户授权；不支持识别、拒绝授权或连接失败时，会提示原因，仍可用按钮画画和确认。
- 单段语音最多 20 秒；连续会话最多 5 分钟或 12 轮。离开页面、停止或异常会终止当前录音/播放。
- 本项目不持久保存原始录音或完整转写；供应商侧的数据处理取决于所配置服务。
- 共创一次规划只发起一次模型调用，不自动付费重试；绘画输出上限 3600 tokens，纯对话 1800 tokens，默认等待预算 18 秒，服务端最多 25 秒。上限不是每次固定消耗，自定义细节越多通常输出越长；移动、缩放、换色和确认仍在本地完成。
- 默认按 IP 分别限制绘画 24 次/分钟、识别 36 次/分钟、播报 36 次/分钟，另受全局限流保护。这不是一幅画的总笔数限制，也不是付费套餐权益。

## 4. 家长端：查看、理解与回顾

### 4.1 顶部与导航

家长端顶部集中孩子切换、语言、通知和家长头像等入口；家长头像在通知右侧。电脑端保留侧边导航和桌面内容区，手机端使用顶部信息区与底部导航，不把整个桌面页面简单缩成长图。

主要栏目是：**成长概览、创作记录、家庭设置、周报与月报、AI 沟通助手。**

正式家长没有孩子时显示邀请码与加入提示；没有作品时显示真实空状态；网络错误显示重试。只有游客体验使用演示数据。

### 4.2 成长概览

概览用于查看当前孩子的创作情况，包括近期创作数量、已有报告形成的趋势摘要、周期报告状态、本周摘要及最近作品等。

“本周成长摘要”的“查看详情”进入创作记录；电脑端“最近一幅作品”右上日期或箭头用于展开完整解读。主题探索和时间轴位于创作记录栏目。家长切换孩子后，作品、报告和请求状态随之切换，不应混入上一个孩子的数据。

概览中的“本月报告”状态卡目前根据是否存在单幅解读显示“已生成”，并不代表自然月摘要已经生成；实际周期报告以“周报与月报”栏目为准。

数量与趋势来自已有记录，不代表系统持续监测孩子，也不应理解为心理诊断。

### 4.3 单幅作品解读

**电脑端流程：成长概览 → 最近一幅作品右上日期或箭头 → 完整解读 → 选择孩子完成分析的作品 → 生成或回看报告。**

当前报告能力包括：

- 展示作品、画面描述和已识别特征。
- 按结构化知识库、年龄条件与冲突规则形成参考结果。
- 展示依据、解释与家长沟通建议；证据不足时明确体现不足。
- 保存生成结果，之后可按作品记录回看，不依赖儿童设备仍在线。
- 可选文字模型补充易读解释，联网或文献能力只作增强。
- 删除所选分析记录，并更新受其影响的周期摘要。

**来源区分：**共创时，Nilo 规划会看已确认的完整画面；儿童成长分析只使用可分离的孩子笔迹。家长展示的图片可以是孩子与 Nilo 的合成作品，并保留共创来源说明。

**删除范围：**当前“删除所选画作”删除的是家长侧分析记录及其图片副本，不同时删除儿童历史图画中的可编辑原稿。两者是不同记录。

### 4.4 创作记录、主题和时间轴

| 功能 | 用途 |
| --- | --- |
| 创作记录 | 按月份浏览当前孩子完成分析的作品和日期；卡片以展示为主，没有独立作品详情跳转 |
| 主题探索 | 根据作品中出现的元素与已有记录组织主题观察 |
| 成长时间轴 | 可切换 30 / 90 / 180 天，按时间回顾作品数量和主题 |
| 趋势摘要 | 聚合已有报告形成描述性提示，不根据绘画数量直接推断心理变化 |

只点“保存”、尚未完成分析的儿童作品不会出现在这些家长分析视图中。

### 4.5 周报与月报

操作流程：**进入“周报与月报” → 选择每周或每月 → 浏览摘要 → 刷新或通过上一页 / 下一页浏览 → 按需下载 JSON。**

摘要包括作品数、创作天数、已有解读数、信息不足的解读数量、常见元素、已有建议及来源记录。

- 按北京时间的自然周（周一至周日）和自然月统计。
- 只为**已经结束且有记录**的周期生成摘要；当天新建家庭不会出现虚构历史报告。
- 进行中的周期可先查看创作记录。
- 服务启动、定时任务和页面读取可补齐已结束周期。
- 汇总已有数据，不额外调用模型；删除分析或修改解读后会重新汇总相关内容。

### 4.6 AI 沟通助手

当前家长端助手是**基于已有报告的沟通建议卡片**：整理已有建议、重复出现的画面元素和开放式提问，帮助家长找到具体话题。

使用流程：孩子完成分析 → 家长生成作品解读 → 打开 AI 沟通助手 → 阅读观察和建议 → 选取合适的问题与孩子交流。

当前没有家长自由输入、多轮聊天或语音对话入口；没有报告时会提示等待。游客展示固定示例卡片。

### 4.7 家庭设置与头像

- 复制家庭邀请码，让其他孩子注册加入。
- 查看关联孩子，修改孩子出生日期；年龄条件用于后续报告，不凭画面猜年龄。
- 在顶部更换家长头像，可选预设或上传图片。设置页退出登录区域的头像只展示，并与顶部同步。
- 退出登录位于设置的上部。退出账号和注销家庭是两种不同操作。
- 正式家庭可以从设置中重新播放新手引导。
- 注销整个家庭需要家长密码及指定确认文字；成功后清理在线家庭数据并撤销相关会话。

头像目前是当前浏览器的本地设置，不是云端头像同步。备份文件、用户已下载的副本和外部服务留存不会因家庭注销而同时消失。

### 4.8 成长档案与导出

完整成长档案页面支持按月份查看，以及导出全部或本年成长册。

- 导出格式为内嵌原图和已有解读的独立 HTML，离线打开后可用浏览器打印成 PDF。
- 未生成解读的记录不会因为导出而自动批量调用模型。
- 图片读取失败时会中止导出并提示，避免生成缺图档案。
- 周报/月报另支持 JSON 下载。

**当前入口限制：**档案路由 `/parent/archive` 已实现，但主界面尚缺少直接跳转按钮。登录家长端后，可在家长端地址后输入该路径，例如 `http://localhost:5174/parent/archive`。

## 5. 推荐的完整使用流程

### 流程 A：快速体验，不创建家庭

1. 官网进入儿童端，选择游客体验。
2. 在小屋点击 Nilo，打开大门。
3. 选择自己画或一起画，试用笔刷、颜色、图形轮廓和背景音乐。
4. AI 服务可用时，主动邀请 Nilo；检查投影，调整后确认。
5. 保存到本机，或下载 PNG；进入历史图画确认可继续画。
6. 返回官网，进入家长游客空间，查看带演示标识的概览与建议。

儿童游客画作不会自动进入家长演示家庭；这两个体验空间不是绑定家庭。

### 流程 B：真实家庭日常使用

1. 家长注册，获取家庭邀请码。
2. 孩子用邀请码注册昵称与创作码。
3. 家长在家庭设置填写孩子出生日期，并选中该孩子。
4. 孩子进入小屋，新建画作，选择模式并创作。
5. 需要 Nilo 帮忙时，通过头像交接回合，或使用麦克风提出要求；先投影再确认。
6. 中途点“保存”；想让家长回顾时，点“完成”，等待分析成功。
7. 家长查看新增记录，在电脑端点击最近作品右上日期或箭头展开完整解读，生成或回看单幅报告。
8. 参考沟通建议和主题记录，与孩子聊画里的故事。
9. 自然周或月结束后查看周期摘要，必要时导出档案。

### 流程 C：继续完成旧画

1. 儿童小屋点击“历史图画”木板。
2. 选择已保存作品进入画布。
3. 继续绘画、撤销笔迹或邀请 Nilo 共创。
4. 点“保存”更新可编辑作品；需要产生新的家长分析记录时，再点“完成”。

## 6. 中英文与设备适配

| 项目 | 当前行为 |
| --- | --- |
| 中英文切换 | 通过页面顶部语言按钮即时切换，不清空画布或表单 |
| 偏好记忆 | 保存在当前浏览器、当前站点；同源标签页同步，独立域名或不同端口不保证共享 |
| 内容翻译 | 界面、规则文案和新报告可按语言展示；用户昵称、作品原文和历史自由文本不自动翻译 |
| 官网艺术英文 | 品牌标语保留英文设计 |
| 家长电脑端 | 侧边导航与桌面排版；内容较多的区域按页面设计滚动 |
| 家长手机端 | 顶部信息区、底部导航和紧凑卡片；与桌面布局分别适配 |
| 儿童手机端 | 静默尝试锁定横屏，必要时在首次点击后尝试全屏；不显示旋转引导阻断层 |
| 平板与电脑儿童端 | 不执行手机方向锁定；画布根据可用空间适配 |

网页不能保证所有手机浏览器都允许方向锁定；如果浏览器拒绝或不支持，页面继续可用，不代表设备一定会物理旋转。

**当前手机家长端限制：**最近作品卡及完整解读入口仅在桌面宽度显示，手机常规导航尚缺少生成/删除单幅解读的入口。现阶段这些操作应使用电脑端。历史列表、长报告和档案也并非所有屏幕下都无需滚动。

## 7. AI、数据与运行支持

### 7.1 AI 功能分别依赖什么

| 能力 | 支持方式 | 是否需要额外配置 |
| --- | --- | --- |
| 小屋互动、基本绘画、保存与续画 | 前端交互及作品接口 | 不需要 AI 模型 |
| Nilo 看画共创 | 视觉/文本模型产生受约束提案，前端校验和绘制 | 需要可用的 `LLM_*` 服务 |
| “完成”后的画面描述 | 视觉提取客观特征，再生成描述性反馈 | 需要视觉服务 |
| 家长基础解读 | 基于已有特征的结构化知识库、年龄门控、冲突处理和确定性评分 | 已有有效分析时，基础规则不依赖再次调用语言模型 |
| 家长说明增强 | 文本模型补充解释 | 可选；失败保留基础报告 |
| 文献参考 | PDF 索引、Python、Chroma 和独立 embedding 配置 | 可选，需要先安装和建索引 |
| 联网建议 | Bocha 搜索补充沟通材料，不修改评分 | 可选，需要独立配置 |
| 云端语音 | ASR 识别和 TTS 合成 | 单独配置 `VOICE_*` |
| 周报/月报 | 汇总已有记录 | 不新增模型调用 |

报告保留知识库版本、证据及审计信息。数字画板没有实际采集笔压等证据时，不将其当作判断依据。报告分值属于启发式参考，不是心理健康概率或诊断结果。

### 7.2 数据保存与权限

- 正式家庭的账号、作品、分析和报告保存在服务端；图片通过受保护接口访问。
- 家长只查看同家庭孩子的数据，儿童账号不能获取家长完整报告及趋势。
- 可编辑作品与家长分析记录分别保存；保存、分析、删除的作用范围见前文。
- 语音、共创故事与头像不是无限云端记忆：完整对话不持久保存，故事摘要和头像等偏好主要保存在当前浏览器。
- 服务端提供备份、图片完整性审计及恢复到新目录的脚本；这些是运维工具，不是用户界面按钮。

### 7.3 本地启动

使用 Node.js 24，在仓库根目录安装依赖：

```bash
npm --prefix server ci
npm --prefix frontend ci
```

将 `server/.env.example` 复制为 `server/.env`，按实际服务填写配置。密钥仅保存在服务端；示例模型名不保证在所有账号中可用。

终端一启动后端：

```bash
npm --prefix server run dev
```

终端二同时启动官网、家长端和儿童端：

```bash
npm --prefix frontend run dev
```

后端默认 `3001`，三个前端默认 `5173 / 5174 / 5175`。前端启动命令不包含后端；只启动官网进程不足以保证独立端入口和 API 都可用。

生产部署、跨域地址、语音和文献索引配置详见文末链接。
