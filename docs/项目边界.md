# 项目边界

> 当前实现说明，更新于 2026-09-06。替代早期“不存图片、非登录家长确认、无向量库”的 MVP 范围。具体完成度见 [功能完成度](功能完成度.md)。

Luma 提供儿童创作陪伴与家庭观察参考。儿童自由绘画，家长回看作品、已有解读与陪伴建议。项目没有临床效度验证，不应宣传为已验证的筛查、诊断或治疗工具。

## 已实现范围

| 模块 | 当前范围 |
| --- | --- |
| 儿童体验 | Nilo 场景互动、自由绘画、图形热身、画笔/橡皮/撤销/清空、PNG 下载、当前会话草稿 |
| 画作理解 | 视觉服务提取完整快照；逐维置信度门控；儿童模板反馈与固定开放提问 |
| 家庭账号 | 家长邮箱密码、儿童昵称和创作码、邀请码、多孩子；服务端权限和会话轮换 |
| 原图与历史 | 正式儿童提交保存受控原图、特征、反馈；分页查询和跨设备家长解读 |
| 家长报告 | 确定性知识库评分、证据 ID、审计；可选文本说明、文献背景和联网建议 |
| 描述性回顾 | 作品主题、时间轴、历史趋势、已结束周期的周报/月报 |
| 数据管理 | 家长填写生日、单幅删除、成长档案 HTML 和周期 JSON 导出、整个家庭注销 |
| 运行工具 | 单进程静态托管、CORS/限流、内嵌媒体备份、恢复与媒体审计 |

## 当前未实现或不提供

| 能力 | 边界 |
| --- | --- |
| 支付、订单、权益控制 | 按当前产品决定暂不实现；计划页仅开放体验与后续规划 |
| 自由文字/语音对话 | 沟通助手呈现现有建议，不是可发送消息的聊天机器人 |
| 长期 AI 记忆、多轮自主推理、主动通知 | 没有相应存储、任务或推送链路；周期报告是站内汇总，不发送邮件/微信 |
| 数字笔压、真实擦除行为分析 | 画板未测量，评分排除依赖这些特征的规则 |
| 自动心理变化预测、诊断或治疗 | 不属于当前产品能力；作品计数与模型观察不能替代专业评估 |
| 第二位家长加入、密码找回 | 没有完整流程；当前每个新家长账号创建一个家庭 |
| 云端草稿与跨设备头像同步 | 草稿限当前浏览器会话；头像是本机偏好 |
| 全环境即时数据抹除 | 注销清理在线家庭数据并撤销会话，备份、下载件和外部服务留存各有生命周期 |

## 输出与数据约束

1. 正式报告、周期报告和趋势仅同家庭家长可访问。儿童本人可看作品和描述，历史接口不返回家长报告。
2. 描述来源标为 AI 画面描述，不能写成孩子原话；正式家庭无记录显示空状态，不能混入游客示例。
3. `confidence` 是启发式参考分值。默认上限 0.85、阈值等是代码配置，不是模型准确率或经过验证的概率。
4. 信息不足保留 0；未见明显风险信号与乐观平稳分别处理。零命中和信息不足允许空证据列表，有引用时必须存在于知识库。
5. 文本增强只解释既有结果；文献和搜索内容不改变评分。失败时保留基础报告。
6. 正式报告由服务端读取作品与生日，不相信客户端替换的特征/年龄。重复提交按孩子与幂等键隔离。
7. 密钥放在服务端环境中。图片访问使用 Authorization 请求头，禁止把令牌放进 URL。

## 验证范围

代码测试覆盖确定性逻辑与组件状态，不等于真实模型、真实触控设备或生产环境验收。历史研究记录仅用于知识整理，不能直接转为产品有效性承诺。
