# 项目边界

> 修改本文件需双方确认，以文档为准。来源：20260724 讨论录音 + docs/plans/2026-07-25-mvp-implementation.md

## 产品一句话

儿童自由绘画 → AI 克制反馈 → RAG 情绪判定（倾向 + 置信度）→ 结果仅给家长。**是情绪预警工具，不是诊断工具。**

## ✅ In Scope（MVP 必须）

| 模块 | 内容 |
|------|------|
| 画板 | 自由绘画、笔触/颜色、导出图片（client） |
| AI 克制反馈 | 仅描述性反馈（"我看到你画了…"），**非诱导式**，不追问情绪 |
| 特征提取 | 多模态 LLM（o3-pro）→ 结构化特征 JSON（元素、颜色、构图、笔触、涂改） |
| RAG 判定 | 特征 → 知识库标签匹配 → 情绪倾向 + 置信度 |
| 结果页 | 情绪倾向 + 置信度数值 + 知识库依据 + 家长沟通建议（非干预方案） |
| 知识库工具 | JSONL 数据格式、校验脚本、种子数据（含文献出处） |
| 用户账号（2026-07-25 变更） | 家长邮箱注册/登录 + 孩子昵称+创作码 + 家庭邀请码；SQLite 单文件库，scrypt 密码哈希，Bearer token 会话（30 天） |
| 画作历史（2026-07-25 变更） | 登录孩子的 analyze/report 落库（仅存特征 JSON + 报告 JSON，**不存画作图片**）；家长可查历史解读。纵向趋势判定仍属 v2 |

## ❌ Out of Scope（明确不做）

| 不做 | 原因（讨论共识） |
|------|------|
| 心理疾病诊断 | 只做情绪预警，"宁可信其有"但不下结论 |
| 干预/治疗方案 | 由家长自行沟通，产品只展示监测结果 |
| 文字/语音聊天引导 | 语言修饰导致信息失真（讨论核心结论） |
| AI 主动绘画引导 | AI 画风主观干扰强，判定可信度降低 |
| 成人版 | 儿童/成人心理学体系差异大，垂直做儿童 |
| 向量数据库 | v2 再做，MVP 用标签匹配足够 |
| 多幅画纵向趋势判定 | v2（历史数据已落库，趋势判定算法另议） |
| 画作图片存储 | 只存结构化特征与报告，原图不留存（儿童隐私最小化） |

## 🚫 Hard Constraints（输出红线）

1. 输出文案**绝不出现疾病名**（抑郁症、多动症等），只用情绪倾向词：乐观平稳 / 焦虑倾向 / 低落倾向 / 需要关注
2. 每条判定必须引用知识库条目 ID（可追溯文献依据）
3. 置信度永远展示；< 阈值（默认 0.7，env 可覆盖）输出"信息不足，建议继续观察"
4. AI 反馈只允许**描述画面 + 开放式提问**，禁止诱导性提问（"你是不是很难过"）
5. **孩子视角全程看不到判定结果**，判定只给家长
6. API key 等敏感配置只存 `server/.env`（已 gitignore），禁止硬编码
7. 特征提取必须带 per-feature confidence，< 0.5 的特征不得进入 RAG 判定
8. 结果页渲染前校验引用条目 ID 真实存在，查无此条 → 降级"信息不足"
