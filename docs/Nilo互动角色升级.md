# Nilo 互动角色升级

儿童端的适配目标是桌面网页与平板横屏、竖屏；本轮不提供手机专属布局。首页保留水彩小屋场景、创作大门，以及棕色毛发、青绿色围巾和星星提灯的 Nilo。

## 角色素材与呈现

角色从整张图片形变升级为分层精灵动画。`frontend/src/assets/images/nilo/nilo-puppet-atlas.png` 是一张包含身体、尾巴、持灯手臂、击掌手臂、围巾、提灯和三种表情的图集。生成图集保留白色底色，原始文件不是已经去底的透明角色素材。

`NiloSprite.tsx` 为每个部件指定图集坐标与 SVG 轮廓裁切，渲染时通过 `clipPath` 隐去白底。三个头部表情共享同一轮廓，并使用同一图集图片。部件的显示效果不依赖正片叠底；灯光、腮红、阴影和粒子由独立图层呈现。

`NiloCharacter.tsx` 负责各部件动作、表情与交互状态，`nilo-character.css` 负责角色绑定、呼吸、提灯摆动及视觉反馈。各部位的按钮放在对应动作图层内，让触碰区域随部位一起移动。

## 六种互动

| 部位 | 回应 |
| --- | --- |
| 头 | 轻轻歪头、靠近，闭眼微笑 |
| 鼻子 | 短暂惊喜表情，送出小泡泡 |
| 空着的手 | 抬起手臂击掌，出现星光 |
| 肚子 | 身体轻颤、闭眼笑，围巾稍后跟着晃动 |
| 尾巴 | 尾巴独立摇动，头部轻轻回应 |
| 提灯 | 提起星星灯，灯光增强，暖光映到脸上 |

每次互动分为察觉、回应、恢复三个阶段，并轮换两句短回应。重复触碰会清理上一次互动的定时器，避免旧动作恢复时覆盖新动作；点击间隔限制为 220 毫秒。角色等待时轻微呼吸、偶尔眨眼，鼠标移动可触发有限幅度的头部跟随。触摸输入不触发鼠标跟随。

角色支持键盘聚焦和激活、显示互动位置的提示按钮，以及用于朗读回应的状态区域。减少动态效果设置会关闭肢体运动与视线跟随。页面隐藏或开门离开时暂停角色并清理互动状态。

## 桌面与平板构图

场景和大门使用相同的 7:4 插画坐标。桌面及横屏平板按视口覆盖构图；竖屏平板使用相同的横屏场景尺度，并移动镜头和角色位置，让大门与完整尾巴留在画面内。竖屏插画上下边缘柔和过渡到纸色背景。极宽窗口限制场景宽度，避免角色脚部被裁切。

导航考虑浏览器安全区域，声音、帮助按钮及退出入口保留至少 44 像素的触碰高度。角色舞台保持正方形。
