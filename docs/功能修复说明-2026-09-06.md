| 审查项 | 处理结果 |

| F05 儿童报告权限 | 儿童不能生成/写入报告、不能访问趋势；儿童画作历史的 report 为 null；匿名不能查询真实 analysisId |

| F07 多孩子串显 | 查询结果按 childId 关联并取消过期更新；解读组件按孩子重新挂载；退出/换账号不接纳旧刷新响应 |

| F10 历史截断 | 后端分页并返回 total/nextOffset，前端读取全部页；趋势不再在过滤前截断 30 条 |
| F11 时间排序/范围 | 保留服务端时间顺序分组；近 4 周没有作品则显示真实空窗口，不用旧记录填数 |
| F12 无限加载 | 无孩子、游客和请求失败均有收敛状态 |
| F13 报告生成后不刷新 | 生成/删除后通知概览重新读取数据，并刷新解读历史及趋势 |
| F14 token 状态不同步 | 轮换同步 localStorage 与 React；请求使用当前会话 token；并发刷新共享结果；退出后旧请求不能恢复登录 |
| F15 年龄来源缺失 | 账号表增加 birth_date；家长在设置中填写；真实报告忽略客户端 childAge，按档案生日计算年龄 |

| F17 图片与备份 | 失败落库清理图片；同家庭家长可删除画作和解读；备份内嵌图片和 SHA-256，提供拒绝覆盖的恢复脚本、缺图与孤儿审计 |

额外修正：知识库弱笔触条件 `weak` 兼容特征枚举 `light`；数据库默认路径使用跨平台 URL 转换。概览中的“表达意愿/想象丰富度”替换成可以核实的作品数/元素种类。

## 新接通的功能

- 家长“设置 → 孩子管理”可填写所选孩子出生日期。修改后，新生成的报告采用该年龄。
- “完整解读”可选择历史画作生成报告、回看报告、删除所选画作。删除需在界面再次确认。
- “完整成长档案”可生成本年成长册、导出全部作品。下载为包含原图与已有解读的独立 HTML，可离线打开，并通过浏览器打印为 PDF。图片获取失败会终止导出并提示，不把缺图文件当作成功。

## 数据与接口迁移

服务启动时自动为 SQLite 增加 `accounts.birth_date`、`analyses.submission_key` 和幂等索引，不清除已有数据。旧记录继续可读；此前已经累积错误的特征、重复作品或错误趋势不会自动重写，避免无依据修改历史。需要时由家长按实际作品重新处理。

正式报告请求现在要求家长 token 和 analysisId；旧的“孩子 token 生成报告”集成需要更新。匿名 features 演示仍可调用，但不能绑定、读取或回写真实作品。

数字画布不采集真实笔压与擦除操作次数。本次选择排除这些证据，不能将其描述成已经实现了过程行为测量。

## 备份与恢复

```bash
cd server
npm run backup
node scripts/restore.mjs backups/luma-具体时间.sqlite /新建且不存在的恢复目录
node scripts/media-audit.mjs
```

备份 CLI 自动加载 `server/.env`。新备份是内嵌媒体的 SQLite 包，不应直接覆盖线上 data.sqlite。恢复脚本先校验数据库与全部原图，输出新的 data.sqlite 和 uploads；核验后将服务 DB_PATH、UPLOAD_DIR 指向恢复结果。原数据库与旧图片不受影响。

`media-audit.mjs` 默认只报告缺图和超过一天的无引用文件。人工核实后可使用 `--remove-orphans` 清理受控目录里的孤儿文件。历史备份仍包含删除前的数据，按保留周期清理；这不是立即从全部备份抹除数据的机制。账号注销及完整的家庭数据治理仍需单独交付。
