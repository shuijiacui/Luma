# 情绪输出与参考分值标准

> 当前工程语义，2026-09-06。产品是创作陪伴与观察参考，没有经过临床有效性验证。历史文献整理见 [早期记录](history/情绪判定标准-早期研究记录.md)，其研究数据不能直接作为 Luma 的准确率或适用性结论。

## 六类输出

| 输出 | 代码含义 | 呈现要求 |
| --- | --- | --- |
| 乐观平稳 | 积极组命中并满足主分支条件 | 不将其扩展成孩子整体健康结论 |
| 未见明显风险信号 | 特征有效，但当前知识库零命中 | 与乐观平稳区分；空证据不代表积极证据 |
| 焦虑倾向 | 负向组满足主分支和至少两个簇要求 | 仅为画面规则的参考结果 |
| 低落倾向 | 同上 | 同上 |
| 需要关注 | 弱信号、冲突、差距不足或单簇强信号 | 不要求分值必然高于 0.7 |
| 信息不足 | 特征不足、无有效引用、兜底或输出校验失败 | 分值保留 0，不替换为积极状态 |

## 分值语义

接口字段仍名为 `confidence`，界面与说明中应解释为启发式参考分值。默认展示上限 0.85 是配置约束，不是论文测得的效度天花板。视觉模型的逐维 confidence 也只是模型自报值，不能与报告分值混为一谈。

知识库权重、组间合成和映射公式见 [RAG 设计](RAG设计.md)。参数的可达性测试、代码测试及文献可追溯性均不能证明概率校准或个体判断正确。

## 儿童与家长边界

儿童只得到画面描述与开放提问，不能访问真实家庭报告、趋势和周期摘要。家长看到的是 AI 对画面的观察，不是孩子亲口表达；无直接录入的原话来源时不使用“孩子原话”标签。

报告生成从服务端作品读取特征和生日。数字画板未测量真实笔压或擦除次数，相关规则排除。模板与增强输出经过限定字段、来源和红线检查，但仍不能声称完全消除了模型错误。

## 历史与周期

趋势只汇总历史结果。报告不足或最近存在信息不足时不能显示稳定；存在关注类结果时按代码显示 watch。stable 只是近期有效历史结果没有预警标签，不是对现实心理状态的保证。

周报/月报不生成新情绪分类，只统计保存的创作和已有建议。作品数、创作天数和识别到的元素变化不映射成情绪、想象力或表达意愿百分比。
