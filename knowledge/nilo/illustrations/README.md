## 造型与难度

初级参考突出少量清楚的大形状，中级参考增加结构、观察角度与少量识别细节。人物的手脚与道具连接应自然，建筑与物件应有合理结构；植物、风景等题材避免密集纹理。单色轮廓、完整主体与宽松留白，为孩子自己上色、添加和改画留出空间。

这些难度是项目的素材分级，不是按年龄测定的能力结论。孩子可以只描外轮廓，再挑一个自己喜欢的细节。Nilo 根据当前画面和孩子的表达选材；空白画布优先初级参考。“简单一点／太难”优先同题材初级参考，“细节多一点／像真的一样”在同题材中选择更适合观察细节的参考。候选仍受审核状态与实际已登记素材限制，不因某种画法缺失而擅自换题材。

此前人物、建筑批次借鉴一般观察与构图方法，来源包括 [National Portrait Gallery 的人物观察活动](https://www.npg.org.uk/schools-hub/gallery-resource-portrait-explorers)、[Drawing Room 的建筑绘画活动](https://drawingroom.org.uk/learning-resource/drawing-buildings/) 和 [Met 的家庭绘画指南](https://www.metmuseum.org/-/media/Files/Learn/Family%20Map%20and%20Guides/Make%20Your%20Mark.pdf)。来源和适用范围在对应计划文件中；这些资料不是产品图片的来源或授权声明。

## 接入、选择与审核

[index.mjs](index.mjs) 登记可信素材 ID、项目内路径、比例、题材、难度与观察提示。模型只返回素材 ID，不能提供任意网址或图片数据。普通模式和先构思后选材模式均支持 PNG。

插画作为浅灰参考底图，支持看原图、移动、缩放、清除和草稿恢复；孩子画出的笔迹独立保留。参考图不会自动成为笔迹，也不会混入作品导出和画作分析。PNG 没有其他已登记画法时，自动换图流程保留当前参考，不改用模型临时拼出的 SVG。

孩子点击“换一个”后，可在素材面板中看图选择。面板按猫、狗、学校等**具体题材**组织，默认打开当前题材，支持搜索和明确点击切换其他题材。候选展示真实 SVG 或 PNG 预览，以“线条少一些”“细节多一些”“仔细观察画”等措辞说明差异，不要求孩子知道专业风格名称。关闭面板不改参考，选择素材只更换参考图，保留全部儿童笔迹；同媒介尽量保持原画框，跨媒介时按可渲染范围调整尺寸。

只在孩子实际点选且成功替换素材后记录选择。记录包含 subject、materialId、style、difficulty、chosenAt，按真实儿童账号隔离，在当前浏览器最多保留最近 **32 条**；访客只在当前会话保存。模型自动推荐、查看、清除与成人审核均不计作孩子选择。历史选择可调整同题材候选顺序，不隐藏其他画法，也不据此推断孩子的绘画能力。

运行 `node server/scripts/review-nilo-library.mjs`，在 [本机审阅室](http://127.0.0.1:4177/) 逐张保留、下架或撤销审核。可按难度、具体题材、表现形式等条件筛选；未审核的新插画优先展示。审核写入 [curation.json](../curation.json)，后续新推荐和素材选择会跳过下架 ID；已有作品不变。审核和历史清理范围见 [审核使用说明](../material-curation.md)及[清理审计](../curation-audits/2026-09-25-2249.md)。

## 验证与维护

生成结果逐张检查主体轮廓、部件连接、裁切和细节量，不合格图定向重画并保存最终提示词。文件存在与生成检查标记不等同于成人审核“保留”；本批已依据用户的明确指令全部通过，未来新批次仍需独立审核。登记状态以 [expansion-status.json](expansion-status.json) 为准，测试和构建结果见本次交付记录。

新增图片须同时提供实际 PNG、逐图结果记录与可信目录登记；计划中的条目不会自行出现在产品中。图库、运行服务与已构建前端的更新方法见 [知识与素材入口](../README.md)。
