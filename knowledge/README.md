# Luma 知识资产

这里是项目知识资料的统一入口。资料按用途分类；放入目录本身不表示模型已在运行时读取，也不表示文献结论经过本产品验证。

| 分类 | 内容 | 使用情况 |
| --- | --- | --- |
| [画面观察](observation/README.md) | 可见元素、颜色、位置的中英词表 | 新家长报告直接读取，不推断情绪 |
| [5–12 岁创作沟通](child-development/README.md) | 分龄开放问题、Nilo 对话措辞与证据边界 | 新家长报告和共创对话读取沟通词库；研究证据页供人工审阅 |
| [儿童心理研究档案](psychology/README.md) | 31 条旧规则的审计、原始文献与候选映射；已核对的研究背景卡片 | 旧规则已退出新家长报告；精选文献只提供一般背景与局限 |
| [Nilo 绘画与共创](nilo/README.md) | 270 种可执行画法、主题课程、绘画技巧、筛选后的简笔画参考、旧案例、预览和共创试验 | 各资料的默认或兼容流程用途见分类目录 |
| [知识校验工具](scripts/validate.mjs) | 检查心理规则条目的字段、权重和引用一致性 | 从仓库根目录运行 `node knowledge/scripts/validate.mjs` |

`docs/` 保存产品流程、API、架构、部署和联调说明；`rag/` 保存文献检索程序。前端页面中的 Nilo 形象仍属于 `frontend/src/assets/images/nilo/`。`shared/niloRecipes.mjs` 是前后端稳定导入入口，实际画法源码位于 `knowledge/nilo/recipes/`。

维护知识资产时，应记录来源、适用场景、许可和限制，并说明具体由哪个运行流程读取。心理文献 PDF 与 Nilo 参考画服务于不同任务，不应混用为儿童个体心理判断。
