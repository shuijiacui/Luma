# 5–12 岁创作沟通资料

`conversation.json` 为家长报告提供可选的开放式提问，也为 Nilo 共创提供同年龄段的对话措辞。已知生日时，5–7 岁用简短具体的故事问题，8–9 岁邀请讲述过程和情节，10–12 岁把作品含义与分享决定交还给孩子；生日未知或游客使用通用指引。服务端从登录孩子的家庭资料计算年龄段，不采用客户端自报年龄。分层只改变对话措辞，不限制绘画主题、提案形状或大小，也不代表能力评级。孩子可以只画、不回答。

这些是产品沟通文案，不是心理量表或已证实有效的干预。已核对的设计资料、适用限制与下一步验证见[创作对话证据](evidence.md)。资料存在不表示可用于个体推断。
